## 1. Резюме методики

Оценка FutureProof измеряет стратегическое мышление как когнитивный навык — то, как человек думает о будущем, анализирует контекст, строит путь к цели, расставляет приоритеты и генерирует альтернативы.

**Что оценивается:** 5 навыков стратегического мышления, каждый раскрывается через 2 способности. Итого — 10 способностей, каждая оценивается по 5-уровневой шкале.

**Как проводится оценка:** участник читает бизнес-кейс и отвечает на 6 открытых вопросов. Каждый вопрос спроектирован под конкретные способности. Ответы оцениваются параллельно — языковой моделью и человеком-оценщиком. Результаты сводятся в финальную оценку, на основе которой собирается персональный отчёт.

**Единица измерения:** уровень развития способности (L1–L5). Уровни описаны поведенчески — через то, что наблюдается в тексте ответа.

**Как считается балл:** уровни двух способностей навыка **складываются** (балл навыка 2–10), баллы пяти навыков складываются (итог 10–50). Усреднение не применяется — см. §9.

**Как читает судья:** уровень не выбирается сравнением пяти описаний, а определяется процедурой гейтов сверху вниз; каждый пройденный гейт подтверждается дословной цитатой из ответа — см. §10.1.

## 2. Глоссарий

> ⚠ *Для внутреннего использования. Перед передачей участникам или внешней аудитории требует финализации формулировок.*

| Термин | Определение |
|--------|-------------|
| **Метанавык** | Базовая особенность личности или мышления, которая влияет на широкий спектр когнитивных процессов — в том числе на стратегическое мышление, но не только на него. Метанавыки формируются раньше специализированных навыков и значительно медленнее поддаются целенаправленному развитию: они меняются через длительный личностный опыт, а не через тренировку конкретной операции. Не входят в оценку. |
| **Комплексный навык** | Когнитивная способность высокого порядка, которая не сводится к одной операции, а объединяет несколько взаимосвязанных навыков. Развивается через целенаправленную практику, поддаётся оценке и развитию по составляющим. Примеры: стратегическое мышление, системный анализ, критическое мышление. |
| **Навык** | Когнитивный процесс, входящий в состав комплексного навыка. Один из пяти компонентов ядра модели стратегического мышления. Раскрывается через две способности. |
| **Способность** | Наблюдаемый аспект навыка — конкретная когнитивная операция, которую можно оценить по тексту ответа участника. |
| **Уровень развития способности** | Одна из пяти позиций шкалы (L1–L5), описывающая качество проявления способности в ответе. |
| **Описание уровней способности** | Полное описание одной способности по пяти уровням. Включает: счётную единицу, лестницу гейтов, для каждого уровня — условие присвоения, поведенческие признаки, дисквалификаторы и примеры. |
| **Поведенческие признаки уровня** | Описание того, что наблюдается в тексте ответа на данном уровне. Состоит из двух частей: **«делает»** — какие конструкции, логика или паттерны присутствуют; **«не делает»** — чего ещё нет, что отличает этот уровень от следующего. |
| **Гейт** | Условие перехода на уровень, сформулированное как проверяемая логическая формула из да/нет-признаков (`G2`, `G3`, `G4`, `G5`). Заменяет граничный тест v11: тот был вопросом, гейт — формулой с оговорённым порядком проверки. |
| **Признак** | Элементарное да/нет-утверждение внутри гейта. Для каждого признака оговорено, что **засчитывается** и что **не засчитывается**. |
| **Свидетельство** | Дословная цитата из ответа участника, которой судья подтверждает пройденный гейт. Гейт без свидетельства считается непройденным. |
| **Дисквалификатор** | Паттерн, который внешне выглядит как признак уровня, но им не является, и потому уровень не поднимает. |
| **Счётная единица** | То, что судья считает внутри способности (домен, привязанный горизонт, блок маршрута, сценарий, приоритет, альтернатива). Задана явно, чтобы «несколько» и «много» не читались по-разному. |
| **Стена** | Явное разграничение двух способностей: сигнал, который принадлежит соседней способности и здесь не засчитывается ни в плюс, ни в минус. |
| **Потолок наблюдаемости** | Максимальный уровень, достижимый при отсутствии условий наблюдения (например, ПР-2 без стресс-теста в вопросе — потолок L3). |
| **Тип прогрессии** | Логика, по которой способность растёт от L1 к L5. Три типа: наращивание (А), замещение (Б), расширение охвата (В). |
| **Роль способности в вопросе** | Статус способности в конкретном вопросе: **основная** — вопрос спроектирован под эту способность, результат входит в балл; **контрольная** — способность может проявиться, но вопрос не оптимизирован под неё, результат используется для перекрёстной проверки. |
| **Кейс** | Бизнес-ситуация, которую участник читает перед ответами на вопросы. |
| **Вопрос** | Задание для участника, на которое он отвечает в свободной форме. Каждый вопрос создаёт когнитивную задачу и диагностирует определённые способности. |
| **Скоринг** | Процесс оценки ответов участника по описаниям уровней способностей. Проводится параллельно и независимо: языковой моделью и человеком-оценщиком. |
| **Балл навыка** | Сумма уровней двух способностей навыка. Диапазон 2–10. |
| **Итоговый балл** | Сумма баллов пяти навыков. Диапазон 10–50. |
| **Индекс** | Итоговый балл, нормированный в шкалу 0–100: `(Итог − 10) / 40 × 100`. Служит для сравнения между прогонами и версиями. |
| **Флаг** | Пометка в справке для оценщика о том, что оценка требует ручной проверки. Флаг никогда не меняет балл автоматически. |
| **Калибровка** | Процесс сравнения оценок ИИ и оценщика на пилотной выборке. Выявляет систематические расхождения и служит основой для улучшения материалов. |

## 3. Источники модели

Модель стратегического мышления FutureProof построена на пересечении четырёх источников. Вся модель в целом опирается на их совокупность — отдельные навыки и способности не обосновываются через каждый источник по отдельности.

### Академические источники

Были изучены две группы научных материалов.

**Теоретические работы** — исследования, описывающие стратегическое мышление как когнитивный процесс, но не операционализированные в измерительный инструмент:

| Источник | Что описывает |
|----------|---------------|
| Liedtka (1998), Long Range Planning | 5 элементов: Systems Perspective, Intent-Focused, Thinking in Time, Hypothesis-Driven, Intelligent Opportunism. Покрывает горизонт, фокус, системное видение. |
| Bonn (2001), Management Decision | 3 компонента: Systems Thinking, Creativity, Vision. Одна из первых работ, призывающих к разработке инструментов измерения. |
| Nuntamanop et al. (2013), J. of Strategy and Management | Grounded theory, 12 компаний, 7 характеристик. Качественное исследование. |

**Валидированные инструменты** — работы с операционализированными шкалами и психометрическими данными:

| Источник | Что измеряет | Ограничения |
|----------|--------------|-------------|
| Pisapia (2005–2011), STQ | 3 субшкалы: Systems Thinking, Reframing, Reflecting. N > 7 000, α = .89–.93. Наиболее валидированный инструмент. | Самоотчёт; не покрывает горизонт и декомпозицию. |
| Goldman & Scott (2016), J. of Strategy and Management | IBAST: scanning, questioning, conceptualizing, testing. | Унимерный инструмент — не дифференцирует компоненты. |
| Multidimensional Strategic Thinking Scale (2025), Cogent Business & Management | 5 измерений, валидация n=18 + n=184. Близок к нашей модели по числу измерений. | Новейший, ограниченная выборка. |

### Существующие инструменты оценки

Помимо академических инструментов, были рассмотрены практические тесты с элементами стратегического мышления:

- **CliftonStrengths (Gallup).** Домен Strategic Thinking: 8 тем. Наиболее близкие к нашей модели: Strategic (генерация альтернативных путей), Futuristic (образ будущего), Analytical (поиск причин), Ideation (связи между явлениями). **Ограничение:** измеряет стилевые предпочтения, а не уровень развития навыка.
- **Korn Ferry KFLA.** Компетенция «Strategic Mindset». Фрагментирует стратегическое мышление на несвязанные компетенции.
- **CCL Benchmarks.** Затрагивает стратегическое мышление, но не как целостный конструкт.
- **Strategic Thinking Profile Instrument v1.0** (черновик коллег). 4 шкалы: Attention Horizon, Anticipation, Decision Foundation, Systems Thinking. **Ограничение:** биполярные шкалы измеряли стилевые предпочтения, а не уровень компетенции.

### Программа тренинга по стратегическому мышлению

Источником послужила авторская программа Егора Кривошеи, сооснователя FutureProof, по составлению стратегии подразделения или компании: логика программы в целом, а также отдельные упражнения, направленные на развитие навыков, связанных со стратегией. Дополнительный источник — обратная связь участников программы (менеджеры и топ-менеджеры российских компаний), которая легла в основу последующих итераций.

### Образовательная программа Strat OS

Адаптированная и развитая до отдельной программы методика, используемая на тренингах Егора Кривошеи. Анализ программы позволил уточнить и верифицировать состав навыков модели.

## 4. Почему собственная модель

Стратегическое мышление — комплексный навык. Именно поэтому с ним сложно работать: непонятно, что именно развивать, что оценивать и откуда брать обратную связь. Большинство существующих инструментов либо измеряют стратегическое мышление как единый недифференцированный навык, либо фрагментируют его на несвязанные компетенции, либо фиксируют стилевые предпочтения вместо уровня развития.

Наша гипотеза: стратегическое мышление состоит из нескольких когнитивных операций, которые можно описать, наблюдать в тексте ответа и развивать по отдельности. Мы выделяем пять таких операций — навыков ядра. Это не классификация ради классификации: каждый навык соответствует реальной задаче, с которой сталкивается менеджер или руководитель при работе со стратегией.

Второе ключевое отличие — единица измерения. Мы оцениваем не наличие навыка и не стилевую предрасположенность, а **уровень его развития** по поведенчески описанной шкале. Это позволяет получить диагностику, пригодную для развития: не «у вас есть стратегическое мышление» или «у вас нет», а «вот где вы сейчас и вот конкретный следующий шаг».

## 5. Модель

### 5.1 Архитектура модели

Модель стратегического мышления FutureProof устроена как трёхуровневая пирамида.

**Уровень 1 — Метанавыки.** Базовые особенности личности и мышления, которые сами по себе не являются стратегическим мышлением, но существенно влияют на то, насколько эффективно человек может его применять. Примеры (список не исчерпывающий): M1 — Рефлексивная дистанция (premise reflection), M2 — Когнитивная гибкость (frame-switching), M3 — Толерантность к неопределённости, M4 — Системное мышление, M5 — Любопытство и открытость новому, M6 — Интегративная сложность (способность удерживать противоречия). **Не входят в оценку** — они создают условия для работы навыков ядра, но не являются специфичными для стратегического мышления.

**Уровень 2 — Ядро стратегического мышления.** Пять навыков, описывающих работу с будущим, текущим положением и контекстом. Это специфичные когнитивные операции, которые можно наблюдать в тексте ответа и развивать целенаправленно. **Оцениваются.**

**Уровень 3 — Инструменты.** Фреймворки и модели, через которые работает стратег: BSC, OKR, сценарное планирование и др. Инструменты — хард-навыки, которые можно освоить независимо от качества стратегического мышления. **Не входят в оценку.**

Оценка измеряет только ядро — уровень 2.

### 5.3 Определения навыков и способностей

**Навыки:**

| Навык | Определение |
|-------|-------------|
| **Моделирование картины будущего (МК)** | Когнитивный процесс конструирования образов будущего на разных временных горизонтах — от экстраполяции текущих тенденций до проектирования принципиально иных вариантов реальности. |
| **Построение пути к цели (ПП)** | Когнитивный процесс выстраивания маршрута от желаемого будущего к текущему положению: декомпозиция цели на этапы и удержание маршрута при столкновении с ограничениями. |
| **Анализ контекста (АК)** | Когнитивный процесс сканирования внешней среды и аналитической переработки обнаруженных факторов — от выявления отдельных сигналов до построения системной картины взаимосвязей. |
| **Приоритизация (ПР)** | Когнитивный процесс сужения пространства действий до управляемого набора приоритетов с осознанными отказами, обоснованием выбора и его удержанием под давлением. |
| **Генерация стратегических альтернатив (ГА)** | Когнитивный процесс систематического порождения нескольких стратегических вариантов, работающих на принципиально разных механизмах, с привлечением идей из широкого круга областей. |

**Способности:**

| Код | Способность | Определение |
|-----|-------------|-------------|
| МК-1 | Оперирование разными временными горизонтами | Протяжённость временного горизонта, которым оперирует участник при рассуждении о стратегической ситуации, — от ближайшего операционного цикла до поколенческого масштаба. |
| МК-2 | Работа с развилками будущего | Тип конструирования будущего — от линейного продолжения текущих тенденций до проектирования нескольких принципиально различных сценариев развития событий. |
| ПП-1 | Декомпозиция цели и выстраивание маршрута | Степень структурированности и логической обоснованности пути от текущего положения к цели: детализация этапов, явность зависимостей между ними и наличие критериев перехода. |
| ПП-2 | Работа с ресурсами и ограничениями на пути к цели | Характер реагирования на столкновение плана с реальными ограничениями — от снижения амбиций до переосмысления ограничений как задач внутри маршрута. |
| АК-1 | Широта охвата факторов среды | Охват внешней среды при анализе стратегической ситуации: количество областей, замеченных и учтённых участником при формировании картины контекста. |
| АК-2 | Глубина анализа взаимосвязей | Качество аналитической работы с выявленными факторами — от присвоения ярлыков до построения системной модели с причинно-следственными цепочками и обратными связями. |
| ПР-1 | Выделение важного и расстановка приоритетов | Результат процесса селекции: конкретность и ограниченность набора приоритетов, наличие явных осознанных отказов и измеримых ориентиров. |
| ПР-2 | Обоснование стратегического выбора | Качество обоснования сделанного выбора и устойчивость этого обоснования при поступлении новой информации или внешнем давлении. |
| ГА-1 | Самостоятельная генерация альтернатив | Степень инициативности и систематичности в порождении альтернативных вариантов — от единичной реакции на прямой запрос до встроенной в рассуждение привычки исследовать пространство возможностей. |
| ГА-2 | Привлечение идей из разных областей | Широта источникового пространства при генерации идей — от знакомого профессионального контекста до абстрактных паттернов, перенесённых из принципиально иных областей. |

## 6. Три типа прогрессии

Каждая способность прогрессирует от L1 к L5 по одной из трёх логик. Тип определяет ярлыки уровней и характер переходов между ними.

Разные типы прогрессии отражают реальное различие в том, как развивается та или иная способность. Для части способностей рост — это накопление: участник замечает всё больше факторов или генерирует всё больше альтернатив. Для другой части — качественный сдвиг в самом способе мышления: например, переход от реакции на ситуацию к проектированию из цели. Для третьей — расширение масштаба применения одной и той же операции. Единая шкала с одними ярлыками не может точно описать все три логики одновременно — поэтому типы разделены.

### Тип А — Наращивание

Каждый уровень добавляет новый элемент к предыдущему. Подходит для способностей, где рост — это расширение охвата или количества элементов.

| Уровень | Ярлык | Что происходит |
|---------|-------|----------------|
| L1 | Не проявлено | Элементы отсутствуют |
| L2 | Единичный элемент | Замечен один элемент |
| L3 | Множественные элементы | Несколько элементов параллельно |
| L4 | Интегрированная картина | Элементы связаны, зависимости и trade-offs |
| L5 | Системная картина | Обратные связи, петли, переносимые принципы |

### Тип Б — Замещение

Каждый уровень заменяет когнитивную операцию на качественно другую. Подходит для способностей, где рост — это смена способа думать, а не добавление элементов.

| Уровень | Ярлык | Что происходит |
|---------|-------|----------------|
| L1 | Не проявлено | Операция отсутствует |
| L2 | Реактивная позиция | Прямолинейная реакция на стимул |
| L3 | Осознанная позиция | Появляется рамка или цель как фильтр |
| L4 | Интегрирующая позиция | Сравнение, trade-offs, обратная логика |
| L5 | Проектирующая позиция | Конструирование системы, из которой выводятся действия |

### Тип В — Расширение охвата

Одна операция применяется ко всё более широкому масштабу. Подходит для способностей, где рост — это не смена операции и не накопление элементов, а расширение контура, на который она распространяется.

| Уровень | Ярлык | Что происходит |
|---------|-------|----------------|
| L1 | Не проявлено | Операция не применяется |
| L2 | Ближний контур | Привычный контекст |
| L3 | Средний контур | Среднесрочный или смежный контекст |
| L4 | Дальний контур | Долгосрочный или непривычный контекст |
| L5 | За пределами контура | За рамками привычной системы координат |

## 7. Кейс и вопросы как инструмент оценки

Оценка построена на бизнес-кейсе — реалистичной истории компании с данными, персонажами и контекстом. Участник читает кейс, а затем отвечает на 6 открытых вопросов в свободной форме.

Вопросы — не просто задания. Каждый вопрос спроектирован под конкретные способности: создаёт когнитивную задачу определённого типа, которая с высокой вероятностью вызывает проявление нужных способностей в ответе. Это означает, что структура диагностики заложена в вопрос на этапе разработки — до того, как участник написал хоть слово.

Каждая способность получает в вопросе одну из двух ролей — основную или контрольную (подробнее — в разделе 8). Требования к матрице покрытия:

Вопрос здесь — станция ассессмента, то есть одно задание оценщика. Шаги, которые участник проходит внутри станции, отдельными вопросами не считаются.

- каждая способность является основной хотя бы в одном вопросе;
- ни один вопрос не покрывает более 3 основных способностей;
- установка перед началом прямо разрешает опираться на знания и опыт за пределами кейса, если они к нему применимы;
- хотя бы 2–3 способности покрыты более чем одним вопросом — для перекрёстной верификации.

Такая архитектура позволяет получить оценку по всем 10 способностям из одного сеанса работы с кейсом, не перегружая участника специализированными заданиями под каждую способность.

---

## 8. Роль способности в вопросе

Каждая из 10 способностей оценивается в одном или нескольких вопросах. В каждом вопросе способность получает одну из двух ролей:

**Основная** — вопрос спроектирован для дискриминации этой способности. Результат входит в подсчёт балла способности.

**Контрольная** — способность может проявиться, но вопрос не оптимизирован под неё. Результат не входит в подсчёт балла, но сравнивается с результатом по основным вопросам. При расхождении уровней — ставится флаг для ручной проверки.

### Механизм флага при расхождении

Если способность оценена и как основная (в одном вопросе), и как контрольная (в другом), результаты сравниваются:
- **Совпадение (±1 уровень):** норма, дополнительных действий не требуется.
- **Расхождение (≥2 уровня):** в справке для оценщика ставится флаг — способность требует ручной перепроверки. Оценщик проверяет обе оценки, определяет, какой вопрос дал более надёжный сигнал, и при необходимости корректирует итоговый уровень.

Контрольная оценка никогда не влияет на балл автоматически — только через решение оценщика после ручной проверки.

Все 10 способностей входят в балл навыка.

## 9. Скоринг

### 9.1 Единица счёта

Уровень способности переводится в число: **L1 = 1, L2 = 2, L3 = 3, L4 = 4, L5 = 5.**

Оцениваются все 10 способностей. Оценка каждой способности — целое число от 1 до 5; дробных уровней, «L3.5» и «L3–L4» не существует. При неоднозначности действует правило §10.1 (уровень вниз + флаг), а не половинный балл.

### 9.2 Балл навыка — сумма уровней

**Балл навыка = уровень первой способности + уровень второй способности.**

| Навык | Слагаемые | Диапазон |
|-------|-----------|----------|
| Моделирование картины будущего (МК) | МК-1 + МК-2 | 2–10 |
| Построение пути к цели (ПП) | ПП-1 + ПП-2 | 2–10 |
| Анализ контекста (АК) | АК-1 + АК-2 | 2–10 |
| Приоритизация (ПР) | ПР-1 + ПР-2 | 2–10 |
| Генерация стратегических альтернатив (ГА) | ГА-1 + ГА-2 | 2–10 |

Балл навыка — это **сумма, а не среднее**. Среднее сжимает две оценки обратно в шкалу L1–L5 и на этом теряет половину замера: пара 5 + 1 и пара 3 + 3 дают одно и то же среднее 3, хотя описывают разных людей и требуют разных рекомендаций. Сумма сохраняет разницу (6 против 6 — здесь совпадение остаётся, но снимается ложная точность «уровня навыка»), а различие внутри пары выносится отдельным показателем — асимметрией (§9.5).

### 9.3 Итоговый балл

**Итоговый балл = сумма баллов пяти навыков.** Диапазон **10–50**.

**Индекс = (Итоговый балл − 10) / 40 × 100**, округление до целого. Диапазон 0–100. Индекс нужен там, где баллы сравниваются между прогонами, версиями кейса и когортами; в отчёте участнику первичен профиль из 10 уровней, а не индекс.

### 9.4 Ярлыки уровня для отчёта

Балл — число; в тексте отчёта рядом с ним стоит ярлык. Полосы заданы так, что совпадают с полосами усреднённой шкалы v11 (полоса = удвоенное среднее).

**Ярлык навыка по баллу навыка:**

| Балл навыка | Ярлык | Читается как |
|-------------|-------|--------------|
| 2 | L1 | обе способности не проявлены |
| 3–4 | L2 | навык на начальном уровне |
| 5–6 | L3 | навык на рабочем уровне |
| 7–8 | L4 | навык на сильном уровне |
| 9–10 | L5 | навык на верхнем уровне |

**Ярлык профиля по итоговому баллу** (полоса берётся по среднему баллу навыка = Итог / 5, пороги 3 / 5 / 7 / 9):

| Итоговый балл | Индекс | Ярлык профиля |
|---------------|--------|---------------|
| 10–14 | 0–10 | L1 |
| 15–24 | 13–35 | L2 |
| 25–34 | 38–60 | L3 |
| 35–44 | 63–85 | L4 |
| 45–50 | 88–100 | L5 |

Ярлык — этикетка для чтения отчёта. Все решения о развитии принимаются по профилю из 10 уровней, а не по ярлыку.

### 9.5 Асимметрия навыка

Сумма прячет разрыв внутри пары, поэтому разрыв выносится отдельно.

**Асимметрия навыка = |уровень первой способности − уровень второй способности|.**

- **0–1** — навык развит ровно; балл читается как есть.
- **≥ 2** — **флаг «асимметричный навык»**. В справке для оценщика и в отчёте называются ведущая и отстающая способности; ярлык навыка сопровождается пометкой, а рекомендация адресуется отстающей способности, а не навыку целиком.

Флаг асимметрии не меняет балл.

### 9.6 Ограничения зависимостей

- **АК-2 ≤ АК-1.** Нельзя глубоко анализировать незамеченное. Если скоринг даёт АК-2 > АК-1 — флаг ручной проверки.
- **ПР-2 ≤ ПР-1 + 1.** Нельзя качественно обосновать то, что не выделено. Если скоринг даёт ПР-2 > ПР-1 + 1 — флаг ручной проверки.
- **ГА-1 ⟂ ГА-2.** Формального ограничения между ними нет; оси независимы.

Обе способности в паре оцениваются **в изоляции** — судья не подглядывает в соседнюю оценку и не корректирует одну под другую. Ограничения проверяются постфактум, при сведении, и дают флаг, а не автоматическое понижение.

### 9.7 Потолки наблюдаемости

Часть верхних уровней определена через реакцию на условие, которого в вопросе может не быть. Если условия наблюдения нет — верхние уровни недостижимы, и это фиксируется как свойство замера, а не как результат участника.

| Способность | Условие наблюдения | Потолок при его отсутствии |
|-------------|--------------------|----------------------------|
| ПР-2 | стресс-тест: в вопросе вброшена новая или противоречащая информация | L3 (L4 и L5 определены через удержание выбора под давлением) |

В справке для оценщика такая оценка помечается «устойчивость ненаблюдаема».

### 9.8 Флаг расхождения основная / контрольная

Если способность оценена и как основная, и как контрольная (§8):

- расхождение **≤ 1 уровня** — норма, действий не требуется;
- расхождение **≥ 2 уровней** — флаг ручной проверки. Оценщик определяет, какой вопрос дал более надёжный сигнал, и при необходимости корректирует итоговый уровень.

В балл входит только оценка по основным вопросам. Контрольная оценка влияет на балл исключительно через решение оценщика.

### 9.9 Что выдаётся на выходе скоринга

1. **Профиль** — 10 уровней с указанием способности и кода.
2. **Пять баллов навыков** (2–10) с ярлыками и пометками асимметрии.
3. **Итоговый балл** (10–50) и **индекс** (0–100).
4. **Список флагов**: асимметрия, нарушение зависимости, расхождение основная/контрольная, ненаблюдаемая устойчивость, спорный гейт, перепрыгнутая граница.
5. **Свидетельства** — по одной цитате на каждый пройденный гейт (§10.1).

Машиночитаемая форма выдачи — Приложение Б.

## 10. Описания уровней способностей

Этот раздел — основной рабочий инструмент скоринга. Для каждой из 10 способностей здесь дано полное описание всех пяти уровней в едином формате (§10.2), пригодном для чтения языковой моделью-судьёй без разночтения.

### 10.1 Протокол судьи

Протокол обязателен и одинаков для всех 10 способностей. Отклонение от порядка шагов делает оценки несравнимыми между собой.

**Шаг 0. Границы материала.** Судья читает ответ участника целиком, один раз, до начала оценки. Оценивается только текст ответа. Не оценивается: длина, стиль, грамотность, уверенность тона, отраслевая правота утверждений, симпатия к предложенной стратегии.

**Шаг 1. По одной способности за раз.** Способность оценивается изолированно. Сигнал, отнесённый разделом «Стены» к другой способности, здесь не засчитывается ни в плюс, ни в минус. Балл между способностями не переносится: одна и та же фраза может дать высокий уровень в одной способности и не дать ничего в другой — это норма, а не ошибка.

**Шаг 2. Проверка гейтов сверху вниз.** Для способности проверяются гейты в порядке **G5 → G4 → G3 → G2**.

- Уровень = номер **самого высокого пройденного** гейта.
- Если ни один гейт не пройден — **L1**.
- Гейты проверяются на всём ответе целиком, а не на отдельном абзаце.
- Порядок «сверху вниз» обязателен: он не даёт остановиться на первом узнанном признаке и завысить или занизить оценку по первому впечатлению.

**Шаг 3. Свидетельство.** Гейт считается пройденным, только если судья может привести **дословную цитату** из ответа, в которой признак присутствует. Пересказ, вывод «по смыслу», «участник явно имеет в виду» — не свидетельство. Нет цитаты → гейт не пройден.

**Шаг 4. Дисквалификаторы.** Для каждого пройденного гейта судья проверяет список дисквалификаторов уровня. Если цитата-свидетельство подпадает под дисквалификатор — гейт **не пройден**, и проверка продолжается на уровень ниже.

**Шаг 5. Правило неопределённости.** Если после шагов 3–4 остаётся сомнение, пройден гейт или нет, гейт считается **непройденным**: ставится уровень ниже и флаг **«спорный гейт»** с указанием границы (например, `3→4`) и спорной цитаты. Судья никогда не разрешает сомнение в пользу более высокого уровня и никогда не ставит промежуточный балл.

**Шаг 6. Перепрыгнутая граница.** По общему правилу гейты монотонны: пройденный верхний гейт означает пройденные нижние. Единственное исключение — **ГА-1**, где L5 достижим без прохождения гейта 3→4. Если верхний гейт пройден, а нижний нет, уровень берётся **по верхнему**, и ставится флаг **«перепрыгнутая граница»**.

**Шаг 7. Что не поднимает уровень никогда.** Сквозные дисквалификаторы, действующие во всех 10 способностях:

- **объём** — длина ответа, длина списка, количество перечисленных пунктов;
- **величина числа** — названный горизонт, процент, сумма сами по себе;
- **лексика** — слова «система», «экосистема», «синергия», «стратегически», «в перспективе», «всё взаимосвязано» без раскрытой за ними операции;
- **тон** — уверенность, категоричность, эмоциональная насыщенность, драматизация;
- **правильность содержания** — то, что предложенная стратегия кажется судье верной или неверной;
- **пересказ кейса** — воспроизведение того, что уже сказано в материалах, своими словами.

**Шаг 8. Выдача.** По каждой способности судья выдаёт: код, уровень, номер последнего пройденного гейта, цитату-свидетельство на каждый пройденный гейт, список флагов. Форма — Приложение Б.


### 10.2 Формат описания уровня

Каждая способность описана по одной схеме. Схема существует ради одного свойства: судья ни в одном месте не должен достраивать правило сам.

**Шапка способности:**

- **Навык и тип прогрессии** — к какому навыку относится и по какой логике растёт.
- **Что измеряет** — что именно наблюдается и оценивается.
- **Счётная единица** — что судья считает внутри этой способности. Задана явно: без неё «несколько», «широко» и «много» читаются по-разному.
- **Стены** — сигналы соседних способностей, которые здесь не засчитываются ни в плюс, ни в минус.
- **Лестница гейтов** — четыре формулы `G2 … G5`, по одной на границу. Порядок проверки задан протоколом (§10.1).

**Каждый из пяти уровней:**

- **Правило входа** — абзац, который говорит, **сколько и каких** признаков нужно, чтобы уровень был присвоен, и что при этом ещё не наступило. Правило записывается явной формулой сочетания: «один обязательный признак», «все три», «хотя бы один из трёх», «конъюнкция блоков A и B». Список признаков без правила сочетания не допускается: модель в такой конструкции достраивает правило сама.
- **ДЕЛАЕТ — обязательные признаки.** Пронумерованный список с указанием, сколько нужно. Только эти признаки проверяются. У каждого оговорено, что **засчитывается** и что **не засчитывается**.
- **ДЕЛАЕТ — типичные формы уровня.** Помечены как необязательные: служат для узнавания, не для проверки. Их отсутствие уровень не отменяет, их наличие уровень не доказывает.
- **НЕ ДЕЛАЕТ** — записывается как **условие выхода** на следующий уровень: чего ещё нет и что должно появиться, чтобы уровень сменился. У нижнего уровня «чего нет» и «как выйти наверх» — одно и то же утверждение, и оно пишется один раз.
- **НЕ ТРЕБУЕТСЯ** — что на этом уровне не обязано присутствовать. Раздел существует, чтобы судья не понижал оценку за отсутствие того, чего уровень не требует.
- **Дисквалификаторы** — паттерны, внешне похожие на признак уровня, но уровень не поднимающие.
- **Примеры** — пары «✅ этот уровень / ❌ соседний» с указанием, какой именно признак присутствует, отсутствует или дисквалифицирован.

**Правила записи, обязательные для всего раздела:**

1. Ни один признак не формулируется через внутреннее состояние («понимает», «осознаёт») — только через наблюдаемое в тексте.
2. Ни одно «несколько», «много», «широко» не остаётся без числа или без счётной единицы.
3. Термин, встречающийся в методологии один раз, не вводится: используется уже рабочее понятие.
4. Одно и то же правило не повторяется в двух местах уровня. Если правило входа поглощает быструю эвристику — эвристика снимается.
5. Признак, который может быть и иллюстрацией, и требованием, получает явный статус.

### 10.3 Чеклист качества описания уровня

Применяется при создании новых способностей или существенном пересмотре существующих.

- [ ] Все 5 уровней заполнены
- [ ] У каждого уровня есть правило входа с явной формулой сочетания (сколько признаков и каких)
- [ ] Обязательные признаки отделены от типичных форм; у типичных форм проставлен статус «не для проверки»
- [ ] Каждый признак наблюдаем в тексте ответа (нет «понимает», «осознаёт» без наблюдаемого проявления)
- [ ] У каждого обязательного признака указано, что засчитывается и что не засчитывается
- [ ] Счётная единица способности задана явно; в описаниях нет неоцифрованных «несколько» и «много»
- [ ] `НЕ ДЕЛАЕТ` записан как условие выхода наверх, а не как переформулировки отсутствия
- [ ] Ярлыки уровней соответствуют типу прогрессии способности
- [ ] Гейты непересекающиеся: ни один ответ не может пройти два гейта по одному и тому же признаку
- [ ] Уровни MECE: нет зазоров, нет перекрытий
- [ ] Логика прогрессии соответствует типу: наращивание / замещение / расширение
- [ ] Описание контекстно-независимо (не привязано к конкретной отрасли или компании)
- [ ] Стены к смежным способностям описаны явно
- [ ] У каждого уровня есть пара примеров ✅ / ❌
- [ ] Раздел «НЕ ТРЕБУЕТСЯ» заполнен для L2–L4
- [ ] Ни одно правило не повторено дважды внутри уровня

### 10.4 Описания способностей

---

### МК-1 · Оперирование разными временными горизонтами

**Навык:** Моделирование картины будущего (МК)
**Тип прогрессии:** расширение (В)

**Что измеряет:** как далеко в будущее простирается зона, за которую участник берёт ответственность, и как он относится к результату на этом горизонте — рассчитывает увидеть его сам или готов вкладываться в то, что созреет за пределами его участия. Уровень определяется тем, что участник **делает** с горизонтом, а не тем, какой горизонт он называет.

**Счётная единица — привязанный горизонт.** Горизонт (точка или интервал в будущем) считается **привязанным**, если в тексте к нему прикреплён хотя бы один якорь из четырёх:

1. конкретное состояние или результат («к концу года выйдем на прибыльность»);
2. действие с обратной связью на настоящее («поэтому уже сейчас делаем…», «для этого в этом году…»);
3. ресурс или вложение, назначенное под этот горизонт;
4. этап маршрута, ведущий к этому горизонту.

Горизонт без единого якоря — **декоративный** и в счёт не идёт. Оценка ставится по **самому дальнему привязанному** горизонту, а не по самому дальнему произнесённому числу.

**Календарные рамки (один перечень на всю способность):**

- **операционный цикл** — недели, месяц, квартал, «до конца года»;
- **стратегический цикл** — 2–5 лет;
- **за пределами стратегического цикла** — 5–10+ лет.

**Стены.**

- **От МК-2.** Здесь не оценивается тип конструирования будущего. Экстраполяция, множественные сценарии, «правила игры перестают действовать» — это МК-2. Слом правил игры **не открывает** ни один гейт МК-1.
- **От ПП-1.** Структура маршрута (этапы, зависимости, вехи) здесь не засчитывается; считается только дальность привязанного горизонта и характер обязательства.
- **Корреляция ожидаема, совпадение — нет.** Возможен дальний горизонт при линейном мышлении (высокий МК-1, низкий МК-2) и сценарии на близком горизонте (высокий МК-2, средний МК-1).

**Лестница гейтов.**

| Гейт | Условие |
|------|---------|
| **G2** | Есть хотя бы один привязанный горизонт за пределами операционного цикла (год и дальше). |
| **G3** | Есть цель на 2+ года, отличная от «того же, только больше», **И** к ней привязаны сегодняшние действия. |
| **G4** | Все три: результат отнесён за пределы стратегического цикла (≈5–10+ лет) **И** названо, что закладывается сейчас ради него, **И** сказано, почему оправдано ждать. |
| **G5** | Хотя бы одно: результат или вложение выходит за пределы собственного участия **ИЛИ** строится система, работающая без участника **ИЛИ** горизонт применён как выбираемая под задачу величина. |

**L1 · Не проявлено**

Вход на уровень — по отсутствию, а не по набору признаков. Убери из ответа всё про «сейчас» и ближайшие операционные шаги: если не остаётся ни одного утверждения о будущем, содержащего состояние, срок за пределами операционного цикла или результат, — уровень этот. Одного такого утверждения достаточно, чтобы его не ставить.

Метки «на этой неделе», «в этом квартале», «до конца месяца» лежат внутри операционного цикла и уровень не поднимают.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Ни одного привязанного утверждения о будущем. Во всём ответе нет фразы, которая называла бы будущее состояние, срок за пределами операционного цикла или результат, ради которого делаются перечисленные действия.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Пустая абстракция будущего. Слово «будущее», «в перспективе», «потом», «долгосрочно» присутствует, но за ним нет ни состояния, ни срока, ни привязанного действия: «надо думать о будущем», «в перспективе всё наладится».
  - Цель равна текущей задаче. Цели нет вовсе, либо названная «цель» — переформулированная операционная задача: «цель — закрыть отток», «цель — навести порядок».
  - Нет второй точки. Есть текущее положение и список дел, но нет отдельно названного «потом», относительно которого этот список выстроен.
  - Срок внутри цикла. Срок назван, но за операционный цикл не выходит.
  - Регистр «пожара». Ответ звучит как тушение: «горит», «срочно», «прямо сейчас», «в моменте», «первым делом». Отсутствие регистра уровень не отменяет, наличие — не доказывает.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** достаточно одного ориентира за пределами операционного цикла, привязанного к будущему результату. «К концу года выйдем на прибыльность» — следующий уровень. «В этом квартале закрыть дыры» — этот.
- **Дисквалификаторы (не поднимают отсюда):**
  - **Большое число без якоря.** «Нам надо думать на 30 лет вперёд», сказанное разово, без единого прикреплённого результата, действия или ресурса. Величина числа сама по себе не поднимает.
  - **Объём.** Длина разбора текущей ситуации к оценке отношения не имеет.
- **Ложное понижение (не занижай):** подробный разбор операционных проблем — не признак этого уровня, если действия привязаны к заявленному направлению за пределами цикла. «Стабилизируем, чтобы через 2 года выйти на новые рынки» — это L3.
- **Примеры:**
  - ✅ «Нужно срочно закрыть отток, разобраться с затратами и нанять людей» → L1: якорей за пределами цикла нет.
  - ✅ «Надо думать о будущем, конечно» → L1: пустая абстракция, якоря нет.
  - ✅ «Сейчас главное — не развалиться, устоять» → L1: горизонт схлопнут в «сейчас».
  - ❌ «К концу года выйдем на прибыльность» → L2: год + прикреплённый результат.

**L2 · Ближний контур**

Вход на уровень — один обязательный признак: в ответе есть хотя бы один **привязанный** горизонт за пределами операционного цикла. Верхняя граница уровня — по отсутствию: привязанной многолетней цели (2+ года), отличной от «того же, только больше», в ответе ещё нет. Самое дальнее произнесённое число на уровень не влияет: считается самый дальний горизонт, к которому прикреплён якорь.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Привязанный горизонт за пределами операционного цикла. Засчитывается: «план на год», «к концу года», «в ближайший год», «в следующем году» — и к этому прикреплён результат, действие, ресурс или этап. Не засчитывается: год, названный без единого якоря; срок внутри операционного цикла.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Будущее как масштабированное настоящее. «Будет как сейчас, только больше / лучше / быстрее» — одномерный рост без качественно иной точки.
  - Далёкое число при ближних обязательствах. Назван горизонт 20–50 лет, но якорей у него нет, а все якоря стоят на ближнем горизонте.
  - Ориентация на один цикл. Ориентиры завязаны на ближайший год, а не на многолетнюю точку, отличную от текущей траектории.
  - Цель, выведенная из наличного. «С учётом того, что есть, можем вырасти до…» — потолок цели задан текущими возможностями.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужна цель на 2+ года, отличная от «того же, только больше», и к ней привязанные сегодняшние действия. Годовой план любой детальности этого не даёт.
- **НЕ ТРЕБУЕТСЯ:** качественно иной образ будущего, сценарии, нелинейность — это МК-2 и здесь не требуется; структура маршрута — это ПП-1.
- **Дисквалификаторы:**
  - **Ловушка большого числа** — ядро уровня. Три разновидности: мечта или лозунг («наша миссия — изменить индустрию за 50 лет»); брошенное число («лет через двадцать…» мимоходом); vision без обязательства — красивый образ на 30 лет без ресурса, этапа и «поэтому сейчас». Проверка: найди самый дальний горизонт и посмотри, прикреплён ли к нему хоть один якорь. Нет якоря → приземляй оценку на тот горизонт, где обязательства реально есть.
  - **Нелинейность не спасает.** Даже нелинейно звучащее большое число без якоря по этой способности остаётся здесь: решает отсутствие привязки, а не линейность (линейность — предмет МК-2).
  - **Детальность годового плана.** Сколь угодно проработанный план на год уровень не поднимает.
- **Примеры:**
  - ✅ «В следующем году вырастем на X%, поэтому нанимаем…» → L2: год + якорь-действие.
  - ✅ «Через 30 лет рынок будет огромным», и больше к этому не привязано ничего → L2: декоративный горизонт при ближних обязательствах.
  - ✅ «Наша миссия — изменить индустрию за 50 лет», лозунгом, без единого этапа под ним → L2.
  - ❌ «Надо думать о будущем» без единого якоря → L1: обязательный признак отсутствует.
  - ❌ «За 3–5 лет должны занять позицию Y — ради этого сейчас перестраиваем…» → L3: многолетняя цель с якорем.

**L3 · Средний контур**

Вход на уровень — оба обязательных признака вместе: многолетняя цель (2+ года), отличная от «того же, только больше», **и** привязанные к ней сегодняшние действия. Верхняя граница уровня — по отсутствию: результат остаётся в пределах текущего стратегического цикла и «при мне», фундамента под отложенную отдачу нет. Названный далёкий срок сам по себе уровень не меняет.

- **ДЕЛАЕТ — обязательные признаки, оба.**
  1. Многолетняя цель. Засчитывается: цель на 2–5 лет, отличённая от текущего плана, порядок «сначала куда, потом как». Цель может быть амбициозной внутри текущей бизнес-модели: участник не обсуждает, оптимальна ли модель, а предполагает работу в ней. Не засчитывается: годовой план любой детальности; формулировка, совпадающая по содержанию с «тем же, только больше».
  2. Привязка действий к цели. Засчитывается: «делаем X сейчас, чтобы через 3 года быть Y». Не засчитывается: цель, названная без единого сегодняшнего шага под неё.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Горизонт в рамке «при мне». «Мой проект», «мой бизнес», «за время моей работы» — отдачу участник застаёт сам.
  - Допущение нелинейности пути. Указание, что путь может потребовать нелинейных ходов.
  - Цель как отдельная точка. Цель названа до разбора возможностей, а не выведена из них.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужны все три признака сразу — результат за пределами стратегического цикла, названный фундамент, закладываемый сейчас, и объяснение, почему оправдано ждать. Пока результат остаётся «при мне и скоро» — уровень этот.
- **НЕ ТРЕБУЕТСЯ:** сценарии и развилки (МК-2); проработанная структура маршрута (ПП-1); отложенная отдача за пределами цикла.
- **Дисквалификаторы:**
  - **Дата вместо содержания.** Названный далёкий срок («через 10 лет»), за которым по сути та же 3–5-летняя цель с запасом по календарю — без отложенной отдачи и без фундамента. Число не поднимает.
  - **Цель из ресурсов.** Многолетняя формулировка, выведенная из наличного («поскольку у нас сильная команда, целимся в…») и не отличающаяся по содержанию от «того же, только больше», → L2.
- **Примеры:**
  - ✅ «За 3–5 лет компания должна занять позицию Y — ради этого сейчас перестраиваем…» → L3: оба признака.
  - ✅ «Через несколько лет хочу вывести направление на [состояние]; для этого в этом году…» → L3.
  - ❌ «Хотим через 5 лет быть лидером» без единого сегодняшнего шага под этим → L2: признак 2 отсутствует.
  - ❌ «Позиция, нужная через 8–10 лет, требует фундамента, который надо начинать строить сейчас, хотя отдача будет нескоро — и вот почему это оправдано» → L4: три признака вместе.

**L4 · Дальний контур — «фундамент под отложенную отдачу»**

Вход на уровень — конъюнкция трёх признаков: результат за пределами стратегического цикла, **и** названный фундамент, закладываемый сейчас ради него, **и** обоснование, почему оправдано ждать. Ни один из трёх по отдельности и ни одна пара уровень не дают. Верхняя граница — по отсутствию: результат ещё «мой», в пределах собственного участия.

- **ДЕЛАЕТ — обязательные признаки, все три.**
  1. Горизонт за пределами стратегического цикла. Засчитывается: результат явно отнесён на 5–10+ лет. Не засчитывается: далёкий срок, за которым стоит та же 3–5-летняя цель.
  2. Фундамент сейчас. Засчитывается: названо конкретное сегодняшнее вложение под будущую потребность — «инфраструктуру Z начать строить сейчас, хотя нужна через N лет». Не засчитывается: «надо готовиться заранее» без названного предмета вложения.
  3. Обоснованная отложенная отдача. Засчитывается: объяснение, почему стоит ждать и вкладываться в отложенное. Не засчитывается: констатация «окупится нескоро» без объяснения, почему это приемлемо.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Предвидение предсказуемых сдвигов. Учёт рыночных или технологических изменений, которых ещё нет, но которые логически выводимы в рамках знакомого мира.
  - Результат в пределах участия. «Мир изменится, но при мне; отдачу застану».
  - Объяснение, почему организация должна идти именно туда, а не только куда.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** результат или вложение должны выйти за пределы собственного участия, либо должна строиться система, работающая без участника, либо горизонт должен применяться как выбираемая под задачу величина.
- **НЕ ТРЕБУЕТСЯ:** сценарии и развилки (МК-2); поколенческие числа; отказ от текущей отдачи.
- **Дисквалификаторы:**
  - **Два признака из трёх.** Отсутствие любого из трёх при результате «при мне и скоро» → L3.
  - **Слом правил игры.** Проектирование из мира с другими базовыми правилами — сигнал МК-2; здесь гейт не открывает.
- **Примеры:**
  - ✅ «Через 7 лет рынок сместится в сторону X (предсказуемо из [логика]); поэтому уже сегодня вкладываемся в компетенцию Y, которая окупится не сразу» → L4: три признака.
  - ❌ «Через 10 лет хотим быть лидером» без названного фундамента и без обоснования ожидания → L3: признаки 2 и 3 отсутствуют.
  - ❌ «Строим институцию и культуру, которые переживут текущую команду» → L5.

**L5 · За пределами контура — «результат за пределами собственного участия»**

Вход на уровень — дизъюнкция: достаточно **одного** признака из трёх. Ограничений сверху нет. Величина горизонта входным условием не является ни в одной форме: 50 лет при результате, который мыслится «моим достижением», остаются предыдущим уровнем.

- **ДЕЛАЕТ — обязательные признаки, хотя бы один из трёх.**
  1. Результат за пределами участия. Засчитывается: прямое указание, что отдачу увидит не он, а преемник или следующая команда, и что участник принимает это как норму. Не засчитывается: далёкий срок при результате, который мыслится «моим достижением, которое я реализую».
  2. Переживающие системы. Засчитывается: институты, культура, инфраструктура, процессы, спроектированные так, чтобы продолжать работать без него. Не засчитывается: «мы строим на века», «хотим оставить след» без названной системы или механизма преемственности.
  3. Горизонт как инструмент. Засчитывается: «для этого решения горизонт — 20 лет, для того — три года» — масштаб времени осознанно выбирается под задачу. Не засчитывается: разные сроки, названные по разным поводам без указания, что масштаб выбран.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Готовность жертвовать текущей отдачей ради результата за пределами участия, с обоснованием.
  - Преемственность как явная проектная задача: «чтобы работало и после смены команды».
  - Объяснение амбициозной цели через глобальные сдвиги, сигналы которых наблюдаются уже сейчас.
- **НЕ ДЕЛАЕТ:** ограничений сверху нет.
- **Дисквалификаторы:**
  - **Число вместо выхода за участие.** Горизонт 30–50 лет с подробной проработкой при результате, который мыслится «моим», → L4.
  - **Слом правил игры.** «Правила игры перестанут действовать» — маркер МК-2. Здесь гейт не открывает: можно быть L5 по МК-2 и L3 по этой способности.
  - **Лозунг о наследии.** «Мы строим на века» без названной системы, вложения или механизма преемственности — лексика, не признак.
- **Примеры:**
  - ✅ «Через 50 лет мир будет выглядеть так, компания — так, поэтому уже сейчас строим институцию и меняем культуру, которые переживут текущую команду» → L5: признаки 1 и 2.
  - ✅ «Для этого решения горизонт — 20 лет, для того — три года» → L5: признак 3.
  - ❌ «Через 30 лет мы будем лидером мирового рынка, и я это построю», с подробным планом → L4: результат в пределах участия.

### МК-2 · Работа с развилками будущего

**Навык:** Моделирование картины будущего (МК)
**Тип прогрессии:** замещение (Б)

**Что измеряет:** тип мышления о будущем — от линейной экстраполяции через одну целевую картину к множественным сценариям и проектированию из «другой реальности». Оценивается операция конструирования, а не дальность горизонта и не богатство исходных данных.

**Счётная единица — образ будущего.** Образ — это утверждение о **состоянии** мира, рынка или компании в будущем, отличное от продолжения текущих задач. Два образа считаются **качественно разными сценариями**, только если они разведены **разными внешними условиями** и дают **разную структуру** рынка или разную роль компании. Различие по величине («лучше / хуже / больше / меньше») новым сценарием не является. Успех и провал одной траектории — не два сценария.

**Стены.**

- **От МК-1.** Здесь не оценивается дальность горизонта. Названный срок без построенного образа остаётся на нижнем уровне, каким бы высоким ни был МК-1.
- **От АК.** АК-1 и АК-2 — аналитический вход: что замечено и как переработано. МК-2 — конструирующий выход: какой образ построен. Богатое сканирование среды при линейном прогнозе = высокий АК, низкий МК-2.
- **От ПР.** Выбор приоритетного сценария сам по себе уровень не поднимает: это сигнал ПР, оцениваемый отдельно. Здесь засчитывается конструирование сценариев.

**Лестница гейтов.**

| Гейт | Условие |
|------|---------|
| **G2** | Есть хотя бы одно утверждение о том, как может выглядеть будущее состояние (а не продолжение текущих задач). |
| **G3** | Есть самостоятельный образ будущего, качественно отличный от линейного продолжения настоящего. |
| **G4** | Построены ≥2 качественно разных сценария с явной развилкой по внешнему условию **И** есть работа над устойчивостью стратегии к ним. |
| **G5** | Базовые правила игры поставлены под вопрос **И** образ опирается на названные наблюдаемые сигналы **И** из образа выведена стратегия. |

**L1 · Не проявлено**

Вход на уровень — по отсутствию: во всём ответе нет ни одного утверждения о будущем **состоянии** мира, рынка или компании. Достаточно одного такого утверждения — пусть самого линейного, — чтобы этот уровень не ставить. Названный срок утверждением о состоянии не является: «через пять лет» без образа остаётся здесь.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Ни одного утверждения о будущем состоянии. Весь ответ — текущая ситуация и тактика; будущее состояние компании, рынка или среды не появляется ни разу.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Будущее как отложенная тактика. «Сейчас разберёмся, потом видно будет» — будущее откладывается, но не конструируется.
  - Пустое упоминание. «Надо думать о будущем» без единого содержательного утверждения о том, каким оно будет.
  - Неопределённость игнорируется. Нет даже намёка, что события могут пойти иначе.
  - «Про будущее пока рано, надо разобраться с текущим».
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** достаточно одного утверждения о том, как может выглядеть будущее. Даже «рынок будет расти» — уже следующий уровень.
- **Дисквалификаторы:**
  - **Названный срок.** Горизонт «через 5 лет» без построенного образа уровень не поднимает. Балл между способностями не переносится.
- **Ложное понижение (не занижай):** подробный разбор текущей операционки не понижает, если где-то заявлено будущее состояние — пусть даже чисто линейное.
- **Примеры:**
  - ✅ «Главное — устоять сейчас, дальше посмотрим» → L1.
  - ✅ Ответ целиком — перечень текущих проблем и тактических ходов → L1.
  - ❌ «Рынок будет расти» → L2: утверждение о будущем состоянии есть.

**L2 · Реактивная позиция — «одна траектория из трендов»**

Вход на уровень — один обязательный признак: есть хотя бы одно утверждение о будущем состоянии. Верхняя граница — по отсутствию: все такие утверждения получены продолжением текущих трендов, самостоятельного образа, качественно отличного от настоящего, нет. Ни горизонт, ни детальность, ни число упомянутых рисков на уровень не влияют.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Утверждение о будущем состоянии, выведенное из продолжения трендов. Засчитывается: «если тренд продолжится, то…», «рынок растёт на X% — значит…», «будет как сейчас, только больше / жёстче / быстрее». Не засчитывается: образ, отличающийся от настоящего не величиной, а моделью, ролью или категорией, — это следующий уровень.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Один прогноз при признанной неопределённости. «Риски есть, но скорее всего будет так» — вариативность названа словами, траектория одна.
  - Масштабированное настоящее. Форма мира та же, меняются величины.
  - Проработанность без ветвления. Прогноз длинный и детальный, но это одна линия.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужен самостоятельный образ, качественно отличный от линейного продолжения настоящего, — иная модель, иная роль, иная категория, а не иная величина.
- **НЕ ТРЕБУЕТСЯ:** дальний горизонт, точность прогноза, богатство исходных факторов, вероятностные оценки.
- **Дисквалификаторы:**
  - **Длинный линейный горизонт.** Экстраполяция на 30–50 лет остаётся здесь: решает линейность, а число — предмет МК-1.
  - **«Признал неопределённость».** Слова «есть риски», «возможны варианты» при одном прогнозе уровень не поднимают. Нужен образ, реально расходящийся с экстраполяцией.
  - **Богатый скан среды.** Много замеченных трендов — это АК-1; линейный вывод из них остаётся здесь.
- **Примеры:**
  - ✅ «Рынок растёт на X% в год — масштабируемся в ту же сторону» → L2.
  - ✅ «Через 30 лет всё будет большим и цифровым» → L2: далёкий горизонт, чистая экстраполяция.
  - ✅ «Оптимистичный сценарий +30%, пессимистичный +5%» → L2: одна траектория с тумблером.
  - ❌ «Компания должна не просто вырасти, а стать [качественно иной образ]» → L3.

**L3 · Осознанная позиция — «один авторский образ»**

Вход на уровень — один обязательный признак: самостоятельный образ будущего, качественно отличный от линейного продолжения настоящего. Верхняя граница — по количеству и способу разведения: набора из ≥2 качественно разных сценариев, разведённых внешними условиями, ещё нет. План Б — признак этого уровня, а не следующего.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Авторский целевой образ. Засчитывается: «компания должна стать [конкретный качественно иной образ]» — иная модель, иная роль, иная категория, сознательный выбор, а не проекция трендов. Не засчитывается: образ, отличающийся от настоящего только величиной; образ, полностью выведенный из продолжения тренда.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Признание вариативности и план Б. Допущение, что образ может не реализоваться, и названный откат.
  - В рамках своего контекста. Образ преимущественно про свою компанию или направление.
  - Формулировка через переопределение категории: «наша цель — переопределить категорию так, чтобы…».
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужны ≥2 качественно разных сценария, разведённых разными внешними условиями, и работа над устойчивостью стратегии к ним.
- **НЕ ТРЕБУЕТСЯ:** дальний горизонт, вероятностные оценки, проработанный маршрут к образу (это ПП-1).
- **Дисквалификаторы:**
  - **«План А / план Б = два сценария».** Успех и провал одной траектории — это откат, а не сценарное мышление.
  - **Косметические сценарии.** «Оптимистичный / базовый / пессимистичный» как одна траектория, докрученная вверх-вниз, — не развилки; это ближе к предыдущему уровню.
  - **Масштаб вместо качества.** Образ, отличающийся от настоящего только величиной, → L2.
- **Примеры:**
  - ✅ «Компания должна не просто вырасти, а стать [качественно иной образ]; если не выйдет — откат к [план Б]» → L3.
  - ❌ «Если [регуляторный сдвиг] произойдёт, рынок разделится на A и Б; делаем стратегию, устойчивую к обоим» → L4.
  - ❌ «Вырастем втрое и станем крупнее всех» → L2.

**L4 · Интегрирующая позиция — «расходящиеся сценарии в знакомом мире»**

Вход на уровень — конъюнкция двух признаков: набор из ≥2 качественно разных сценариев, разведённых явной развилкой по внешнему условию, **и** работа над устойчивостью стратегии к ним. Одного набора сценариев без работы над устойчивостью недостаточно. Верхняя граница — по типу мира: базовые правила игры сохраняются, будущее сложное, но принципиально знакомое.

- **ДЕЛАЕТ — обязательные признаки, оба.**
  1. Набор расходящихся сценариев. Засчитывается: «если [сдвиг X] — рынок пойдёт по A, если [сдвиг Y] — по Б» — разные внешние условия дают качественно разные структуры рынка. Не засчитывается: ветки, разведённые тумблером «хорошо / плохо»; успех и провал одной траектории.
  2. Работа над устойчивостью. Засчитывается: «устойчивы к обоим», «хеджируем [X]», отдельный ход под каждый сценарий. Не засчитывается: перечень сценариев, за которым не следует ни одного решения.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Оценка условий или вероятностей сценариев.
  - Выбор приоритетного сценария с обоснованием. Встречается и на следующем уровне; сам по себе уровень не поднимает.
  - Системный взгляд. В картину входит взаимодействие рынка, технологий, игроков, потребителей, а не только компания.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** базовые правила игры должны быть поставлены под вопрос, образ должен опираться на названные наблюдаемые сигналы, и из образа должна выводиться стратегия.
- **НЕ ТРЕБУЕТСЯ:** большое число сценариев, вероятностная арифметика, дальний горизонт.
- **Дисквалификаторы:**
  - **«Много = высоко».** Десять сценариев внутри знакомого мира остаются здесь. Границу наверх задаёт слом базовых допущений, а не число веток.
  - **Косметические ветки.** Ветки, разведённые тумблером «хорошо / плохо», признак 1 не открывают.
  - **Выбор приоритета.** Сам по себе не дискриминатор — это сигнал ПР.
- **Примеры:**
  - ✅ «Если [технологический сдвиг] произойдёт, рынок разделится на [A] и [Б]; делаем стратегию, устойчивую к обоим, приоритет [A], потому что…» → L4: оба признака.
  - ✅ «Три сценария по поведению [драйвера]; в каждом наш ход отличается; хеджируем [X]» → L4.
  - ❌ «Возможны три сценария развития рынка» без единого решения под них → L3: признак 2 отсутствует.
  - ❌ «Что если сама потребность в [продукте] исчезнет? Сигналы X и Y на это намекают; тогда компания должна быть устроена как [иная модель]» → L5.

**L5 · Проектирующая позиция — «мир по другим правилам, выведенный из сигналов»**

Вход на уровень — конъюнкция трёх признаков: под вопрос поставлено базовое допущение об устройстве мира или отрасли, **и** образ опирается на названные наблюдаемые сигналы, **и** из образа выведена стратегия. Ни один из трёх по отдельности уровень не даёт: слом правил без сигналов — спекуляция, сигналы без построенного мира — сигнал АК, образ без выведенной стратегии — фигура речи. Ограничений сверху нет.

- **ДЕЛАЕТ — обязательные признаки, все три.**
  1. Слом базовых допущений. Засчитывается: «что если сама потребность в [продукте] исчезнет?», «допустим, [базовое допущение отрасли] перестаёт действовать». Не засчитывается: «мир изменится до неузнаваемости», «всё будет иначе» — без названного допущения, которое ломается.
  2. Опора на наблюдаемые сигналы. Засчитывается: названы ранние признаки и показана цепочка «сигнал → логика → образ». Не засчитывается: «другие правила», заявленные произвольно.
  3. Стратегия, выведенная из образа. Засчитывается: ходы выводятся **из** мира по другим правилам. Не засчитывается: путь **к** этому миру без единого решения, следующего из него.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Радикальная трансформация модели как рассматриваемая возможность.
  - Неопределённость как среда проектирования: не мешает действовать, а является материалом.
- **НЕ ДЕЛАЕТ:** ограничений сверху нет.
- **Дисквалификаторы:**
  - **Пустой или sci-fi образ.** «Роботы всё заменят» без цепочки от сигналов и без выведенной стратегии — не этот уровень. Понижай: один яркий образ без сигналов → L3; докрученная экстраполяция → L2.
  - **Богатое обнаружение сигналов без построенного мира.** Это высокий АК, а не уровень здесь.
  - **Зрелищность.** Эффектность образа не поднимает: решают тип операции и сигнальная опора.
- **Примеры:**
  - ✅ «Что если потребность в [продукте] исчезнет? Сигналы [X, Y] на это намекают; тогда компания должна быть устроена как [иная модель] — и вот стратегия из этого» → L5: три признака.
  - ❌ «Через 20 лет всё изменится до неузнаваемости, надо быть готовыми» → L2: ни одного из трёх признаков.
  - ❌ «Мир станет другим: [яркий образ]» без сигналов и без выведенной стратегии → L3.

### ПП-1 · Декомпозиция цели и выстраивание маршрута

**Навык:** Построение пути к цели (ПП)
**Тип прогрессии:** замещение (Б)

**Что измеряет:** структуру рассуждения при построении пути — насколько детально разложен маршрут и обоснована логика последовательности шагов. Оценивается связность маршрута: направление планирования, зависимости, вехи, параллельность, ресурсная соразмерность.

**Счётная единица — блок маршрута.** Блок — это участок пути между текущим положением и целью, названный отдельно. Считаются блоки, а не действия: список из десяти дел без адресата и порядка блоками не является. Отдельно различаются:

- **тематический блок** — направление работы («продукт», «продажи», «стабилизация»);
- **веха** — достигнутый результат, по которому проверяется переход («платформа готова», «доля рынка X»);
- **зависимость** — обоснование порядка через предпосылку: «Y требует результата X»;
- **критерий перехода** — индикатор-результат («этап завершён, когда достигнут [показатель]»). Календарная дата критерием не является.

**Несущий переключатель — направление планирования.** На нижних уровнях участник думает вперёд от настоящего («есть X → можем Y»); начиная с L3 — назад от цели («куда хотим → как дойти»). Этот разворот отделяет реактивную позицию от осознанной.

**Стены.**

- **От ПП-2.** Шаг стоит раньше, потому что следующий требует его результата, — это ПП-1. Шаг стоит раньше, потому что снимает конкретный барьер, — это ПП-2. Ресурс как условие соразмерности этапа («найм займёт 18 мес → этап позже») — ПП-1; ресурс как объект работы («команды нет, но это преодолимо через партнёра») — ПП-2.
- **От МК-2.** Здесь не оценивается, откуда взялась цель и хороша ли она. Блестящий образ будущего с рыхлым путём = высокий МК-2, низкий ПП-1.
- **От ПР.** Порядок «сначала самое важное» — это приоритизация. Для этой способности нужен порядок из структуры пути, а не из важности.

**Лестница гейтов.**

| Гейт | Условие |
|------|---------|
| **G2** | Есть конечная точка, отличная от описания текущей деятельности. |
| **G3** | Произошёл разворот «сначала куда, потом как» **И** путь разложен на ≥2 блока. |
| **G4** | Порядок следует из логики предпосылок («Y требует результата X») **И** промежуточные точки привязаны к результатам, а не к темам или датам. |
| **G5** | Есть системная структура сверх линейной цепочки (параллельность как граф **или** критерии перехода по результату **или** обратные связи) **И** конкретная привязка ресурсов и сроков к этапам, меняющая пейсинг. |

**L1 · Не проявлено**

Вход на уровень — по отсутствию второй точки: в ответе нет конечной точки, отличной от описания текущей деятельности, и потому раскладывать нечего. Достаточно одной названной цели — пусть грубой, вроде «стать №2 на рынке», — чтобы этот уровень не ставить. Число перечисленных дел на уровень не влияет.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Нет конечной точки. Во всём ответе не названо состояние, отличное от «починить то, что сломано сейчас», относительно которого выстраивался бы путь.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Цель равна текущей задаче. «Цель — навести порядок», «цель — закрыть отток» — переформулированная операционка.
  - Список без вектора. Перечень действий без цели, к которой они ведут, и без порядка между ними.
  - Нет разрыва между «где мы» и «куда идём» — есть только «что сломано и что с этим делать».
  - Действий много, но они ни к какой конечной точке не свёрнуты.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** достаточно назвать конечную точку, отличную от текущей деятельности. Даже грубо: «стать №2 на рынке».
- **Дисквалификаторы:**
  - **«Длинный список = план».** Много действий не равно декомпозиции. Нет адресата и нет порядка — уровень остаётся этот, как бы детально список ни выглядел.
- **Ложное понижение (не занижай):** подробный разбор операционки не понижает, если действия привязаны к заявленной отдельной цели.
- **Примеры:**
  - ✅ «Нужно решить отток, подтянуть затраты и усилить команду» → L1: список без адресата.
  - ✅ «Главная задача — стабилизировать и не потерять клиентов» → L1: цель неотличима от операционки.
  - ❌ «Цель — стать №2 на рынке; для этого…» → L2: конечная точка есть.

**L2 · Реактивная позиция — «разрыв виден, моста нет»**

Вход на уровень — один обязательный признак: названа конечная точка, отличная от описания текущей деятельности. Верхняя граница — по отсутствию: разворота «сначала куда, потом как» ещё нет, либо путь не разложен ни на какие блоки. Громкость формулировки цели значения не имеет: цель, выведенная из наличных ресурсов, остаётся здесь.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Конечная точка названа. Засчитывается: состояние, отличное от текущей деятельности, относительно которого видно расстояние. Не засчитывается: переформулированная операционная задача.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Видит разрыв, не строит мост. Дистанция между «сейчас» и целью названа, но остаётся наблюдением.
  - Действия без порядка. Шаги набросаны, но без «что за чем и почему».
  - Цель как производная от ресурсов. «С учётом того, что есть, можем вырасти до…» — потолок цели задан текущими возможностями.
  - Планирование от настоящего. Отталкивается от «что мы умеем», а не от желаемой точки.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужны оба признака вместе — разворот направления (цель задаётся первой, путь разворачивается от неё назад) и разложение пути минимум на два блока.
- **НЕ ТРЕБУЕТСЯ:** качество и амбициозность цели (это МК-2); работа с ограничениями (это ПП-2); метрики.
- **Дисквалификаторы:**
  - **Громкая цель из ресурсов.** «Поскольку у нас сильная команда, целимся в…» — это планирование вперёд от настоящего, уровень остаётся этот.
  - **Порядок по важности.** «Сначала самое важное, потом остальное» — сигнал ПР, а не логика маршрута.
- **Примеры:**
  - ✅ «С нашими ресурсами реалистично вырасти процентов на двадцать и добрать пару сегментов» → L2: цель как функция от наличного.
  - ✅ «Надо и то, и это, и ещё вот это» при названной цели → L2: разрыв назван, порядка нет.
  - ❌ «Цель — лидерство. Сначала стабилизируемся, потом выходим на новые рынки, потом масштабируемся» → L3.

**L3 · Осознанная позиция — «крупные блоки от цели»**

Вход на уровень — конъюнкция двух признаков: разворот направления (цель зафиксирована первой, путь разворачивается назад к настоящему) **и** разложение пути на ≥2 блока. Верхняя граница — по типу связи между блоками: блоки идут один за другим по времени или по теме, но не потому, что следующий требует результата предыдущего.

- **ДЕЛАЕТ — обязательные признаки, оба.**
  1. Планирование от цели. Засчитывается: цель названа до разбора возможностей, шаги выводятся из неё. Не засчитывается: цель, выведенная из наличных ресурсов.
  2. Крупноблочная декомпозиция. Засчитывается: путь разложен на 2–4 больших блока или фазы («стабилизация → экспансия → масштаб»). Не засчитывается: перечень действий без деления на участки пути.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Блоки как направления. Каждый блок — тематическое направление работы, а не веха-результат.
  - Порядок есть, зависимость — нет. Фазы идут одна за другой, но не по предпосылке.
  - Датированная фазировка. «Год 1 — то, год 2 — это».
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** порядок должен следовать из предпосылок («X до Y, потому что Y требует результата X»), а промежуточные точки — быть результатами-вехами, а не темами или датами.
- **НЕ ТРЕБУЕТСЯ:** критерии перехода, параллельность, обратные связи, привязка ресурсов — всё это признаки верхнего уровня.
- **Дисквалификаторы:**
  - **Временнáя последовательность.** Привязка к календарю не равна привязке к результату-предпосылке. Датированная фазировка без зависимости остаётся здесь.
  - **«Направления = вехи».** Тематический блок («усилить маркетинг») — направление, а не веха с проверяемым результатом.
- **Примеры:**
  - ✅ «Цель — лидерство. Сначала стабилизируемся, потом выходим на новые рынки, потом масштабируемся» → L3: фазы есть, зависимости нет.
  - ✅ «Три направления: продукт, продажи, команда — по ним и движемся» → L3.
  - ❌ «Наём senior-команды до масштабирования, потому что масштабировать некому без неё» → L4: зависимость по предпосылке.

**L4 · Интегрирующая позиция — «вехи, связанные предпосылками»**

Вход на уровень — конъюнкция двух признаков: порядок обоснован предпосылкой («Y требует результата X») **и** промежуточные точки привязаны к результатам, а не к темам или датам. Верхняя граница — по форме маршрута: цепочка остаётся линейной, критериев перехода, обратных связей, параллельности как структуры и ресурсной привязки ещё нет.

- **ДЕЛАЕТ — обязательные признаки, оба.**
  1. Явные зависимости. Засчитывается: «инфраструктура Z до выхода на рынок, потому что рынок требует Z». Не засчитывается: «сначала это, потом то» без «потому что требует».
  2. Вехи-результаты. Засчитывается: промежуточные точки — достигнутые результаты. Не засчитывается: тема («усилить маркетинг») или дата («к Q3») в роли промежуточной точки.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Обратная логика от цели к настоящему. «Чтобы к 20XX быть в Y, за 2 года до этого нужно Z, значит сейчас начинаем с…».
  - Ремарка об одновременности. Иногда отмечено, что пара направлений идёт параллельно, — как замечание, не как выстроенная структура.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужны оба блока сразу — системная структура сверх линейной цепочки (параллельность как граф, критерии перехода по результату или обратные связи) **и** конкретная привязка ресурсов и сроков к этапам, меняющая пейсинг.
- **НЕ ТРЕБУЕТСЯ:** полнота маршрута, число этапов, метрики на цель.
- **Дисквалификаторы:**
  - **Ложная параллельность.** Ремарка «это делается параллельно» без различения зависимых и независимых треков верхнего блока не даёт.
  - **Ложная проверяемость.** «Этап завершится к [дате]» — это срок, а не критерий перехода.
- **Примеры:**
  - ✅ «Чтобы через 5 лет запустить [направление], за 2 года до этого нужна платформа; платформа требует данных, которые собираем сейчас, — поэтому первым идёт сбор данных» → L4: оба признака.
  - ❌ «Сначала стабилизация, потом экспансия, потом масштаб» → L3: признак 1 отсутствует.
  - ❌ «Треки 1А и 1Б независимы и идут одновременно; этап 2 стартует, когда 1А достиг [индикатор]; 1Б займёт ~18 мес из-за цикла найма» → L5.

**L5 · Проектирующая позиция — «маршрут как система, соразмерная ресурсам»**

Вход на уровень — конъюнкция двух блоков: **(A)** системная структура сверх линейной последовательности — достаточно одного маркера из трёх, параллельность старшая; **и (B)** ресурсная соразмерность — обязательна. Ни один из двух блоков по отдельности уровень не даёт: богатый граф без ресурсной привязки — предыдущий уровень, ресурсная реалистичность на линейной цепочке — тоже. Ограничений сверху нет.

- **ДЕЛАЕТ — обязательный блок A: хотя бы один маркер из трёх.**
  1. Параллельность как граф. Засчитывается: маршрут разложен в двух измерениях — последовательность этапов и параллельные треки внутри этапа, с явным различением независимых треков и связанных зависимостью. Не засчитывается: «делаем A, B и C» — перечень; засчитывается «A и B развязаны и идут одновременно, C ждёт результата A».
  2. Критерии перехода. Засчитывается: «этап завершён, когда [индикатор-результат]». Не засчитывается: календарная веха «к Q3».
  3. Обратные связи и условные переходы. Засчитывается: результат этапа меняет требования к другим; есть точки проверки и альтернативные ветки — «если к [сроку] [метрика] не достигнута, переключаемся на [альтернативный трек]».
- **ДЕЛАЕТ — обязательный блок B: маркер обязателен.**
  4. Ресурсная соразмерность. Засчитывается: конкретные ресурсы или сроки (люди, деньги, компетенции, календарь) привязаны к конкретным этапам и меняют пейсинг или последовательность — «найм ~18 мес → этап 3 позже». Не засчитывается: «стратегию нельзя сделать за месяц», «на это нужно время», «ресурсы ограничены» — общие места.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Маршрут читается как граф, а не как линия.
  - Явное разделение развязанных и строго последовательных направлений.
- **НЕ ДЕЛАЕТ:** ограничений сверху нет.
- **Дисквалификаторы:**
  - **Труизм про ресурсы** — главная ловушка блока B. «Понятно, что быстро не выйдет» — не оценка ресурсов.
  - **Параллельность как список** — главная ловушка блока A. Несколько перечисленных дел параллельностью не являются.
  - **Дата вместо критерия.** Календарная веха маркер 2 не открывает.
- **Примеры:**
  - ✅ «Треки 1А (продукт) и 1Б (найм) идут параллельно — они независимы. Этап 2 стартует, когда 1А достиг [индикатор]. 1Б займёт ~18 мес из-за цикла найма — раньше этап 3 не начать» → L5: блок A (маркеры 1 и 2) и блок B.
  - ❌ Тот же маршрут без единого срока и ресурса → L4: блок B отсутствует.
  - ❌ «Этапы идут по зависимости, и понятно, что всё это небыстро» → L4: блок A линейный, блок B — труизм.

### ПП-2 · Работа с ресурсами и ограничениями на пути к цели

**Навык:** Построение пути к цели (ПП)
**Тип прогрессии:** замещение (Б)

**Что измеряет:** качество работы с реальностью при столкновении плана с ограничениями — что участник видит (диагностика) и как реагирует (поведение).

**Счётная единица — фактор, оценённый относительно цели.** Фактор засчитывается, только когда он назван **барьером** («мешает достичь X») или **enabler'ом** («помогает достичь X / снимает барьер Y») относительно цели. Проблема, названная как факт или жалоба, счётной единицей не является. Число названных ограничений уровень не задаёт — его задаёт паттерн реакции.

**Две оси уровня, движутся синхронно:**

- **диагностика** — что видит: только барьеры → барьеры и enablers → увязанные барьеры и enablers;
- **реакция** — что делает: снижает цель → удерживает цель → ищет обходной путь → делает ограничение первой задачей ради цели.

**Стены.**

- **От ПП-1.** Ресурс как объект работы (диагностируем, классифицируем, преодолеваем) — здесь. Ресурс как условие соразмерности этапа — ПП-1.
- **От ПР.** Здесь объект приоритизации — ограничения и ресурсы (что снять первым ради цели). В ПР объект — инициативы и направления (что делать, от чего отказаться).
- **От АК.** Назвать факторы среды — АК-1. Переосмыслить их как барьеры и enablers относительно цели — здесь. Богатый скан среды без переосмысления в терминах цели = высокий АК, низкий ПП-2.
- **От МК-2.** Амбициозность самой цели здесь не оценивается.

**Лестница гейтов.**

| Гейт | Условие |
|------|---------|
| **G2** | Хотя бы одна сложность сформулирована как барьер к цели (а не как жалоба или факт). |
| **G3** | Названы enablers, а не только барьеры, **И** цель не снижена автоматически при виде барьера. |
| **G4** | Есть связка «ресурс Y снимает барьер X» **и/или** классификация ограничений (фиксированное / преодолимое) — с названным механизмом преодоления. |
| **G5** | Приоритеты строятся от цели (ограничение = первая задача) **и/или** поставлена под вопрос категория «непреодолимого» — через конкретный механизм. |

**L1 · Не проявлено**

Вход на уровень — по отсутствию: ни один фактор не назван барьером или ресурсом **относительно цели**. Проблемы могут быть перечислены подробно — это ничего не меняет: без цели-якоря барьер не с чем соотнести. Достаточно одной сложности, сформулированной как препятствие на пути к чему-то, чтобы этот уровень не ставить.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Ни одного фактора, оценённого относительно цели. Во всём ответе нет фразы вида «мешает достичь X» или «помогает достичь X».
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Проблемы как факты. «Отток растёт, продукт устарел, кадров не хватает» — список состояний, без «мешает достичь чего».
  - Жалоба или констатация. «Всё плохо», «рынок сложный» — без привязки к движению к цели.
  - Нет якоря-цели. Цель не задана или совпадает с операционкой.
  - Ресурсы не названы вовсе — ни то, что мешает, ни то, что помогает.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** достаточно одной сложности, сформулированной как барьер к цели. «Продукт устарел» — этот уровень; «устаревший продукт мешает выйти в сегмент X, надо обновить» — следующий.
- **Дисквалификаторы:**
  - **Объём констатаций.** Подробность разбора проблем уровень не поднимает.
- **Ложное понижение (не занижай):** слабая цель в ПП-1 не штрафует эту способность автоматически. Проверь, нет ли неявной цели, к которой барьер всё-таки привязан; балл между способностями не переносится.
- **Примеры:**
  - ✅ «У компании отток, устаревший продукт и нехватка людей» → L1: факторы не соотнесены с целью.
  - ✅ «Ситуация тяжёлая, рынок давит» → L1.
  - ❌ «Устаревший продукт мешает выйти в сегмент X» → L2.

**L2 · Реактивная позиция — «ограничение как потолок амбиций»**

Вход на уровень — один обязательный признак: хотя бы одна сложность сформулирована как барьер к цели. Верхняя граница — по двум отсутствиям сразу: enablers не названы, а цель при виде барьера снижается. Достаточно, чтобы цель рефлекторно снижалась, — и уровень остаётся здесь, даже если где-то мимоходом упомянута «сильная команда».

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Барьер, сформулированный относительно цели. Засчитывается: «на экспансию нет бюджета, поэтому…», «технология устарела, догонять поздно». Не засчитывается: та же проблема как факт или жалоба.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Ограничение как данность. «Бюджета нет», «команда слабая», «рынок закрыт» — принимается как неизменное условие.
  - Снижение цели. Реакция на барьер — уменьшить амбицию: «раз так, реалистичнее сделать поменьше».
  - Только барьеры. Названо одно-два ограничения, но не сказано, что могло бы помочь.
  - Нет вопроса «как преодолеть». Барьер закрывает опцию, а не открывает задачу.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужны оба признака вместе — названные enablers и неснижение цели при виде барьера.
- **НЕ ТРЕБУЕТСЯ:** механизмы преодоления, классификация ограничений, интеграция — признаки верхних уровней.
- **Дисквалификаторы:**
  - **«Реализм = зрелость».** Снижение цели часто звучит трезво («будем реалистами»), но по этой оси это низкий уровень. Не повышай за взвешенность.
  - **Ложный enabler.** «У нас хорошая команда» без связи с преодолением барьера или достижением цели — комплимент, а не enabler.
- **Примеры:**
  - ✅ «На международную экспансию нет бюджета, поэтому реалистичнее остаться на внутреннем рынке» → L2.
  - ✅ «Технология устарела, догонять поздно — сфокусируемся на том, что умеем» → L2.
  - ❌ «Барьеры: финансирование, технология. Сильные стороны: команда, база. Цель оставляем» → L3.

**L3 · Осознанная позиция — «две стороны, два списка»**

Вход на уровень — конъюнкция двух признаков: названы enablers, а не только барьеры, **и** цель не снижена автоматически. Верхняя граница — по отсутствию связи: барьеры и enablers идут двумя независимыми списками, связок и классификации нет. Аккуратная разметка на четыре квадранта остаётся здесь: матрица не равна интеграции.

- **ДЕЛАЕТ — обязательные признаки, оба.**
  1. Две стороны. Засчитывается: названы и препятствия, и помогающие факторы относительно цели. Не засчитывается: комплимент компании без связи с целью или барьером.
  2. Цель удерживается. Засчитывается: амбиция не снижается рефлекторно при виде барьера. Не засчитывается: удержание на словах при фактическом урезании цели дальше в ответе.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Диагностика без синтеза. Барьеры и ресурсы перечислены как два независимых списка.
  - SWOT-разметка. Четыре аккуратных квадранта без причинных связей между элементами.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужна хотя бы одна связка «ресурс Y снимает барьер X» и/или классификация ограничений на фиксированные и преодолимые — с названным механизмом.
- **НЕ ТРЕБУЕТСЯ:** приоритеты, механизмы, переворот ограничения — признаки верхних уровней.
- **Дисквалификаторы:**
  - **Матрица вместо интеграции.** Разложенные по квадрантам списки связями не являются.
  - **Тест давления.** Если при усилении давления в ответе всё же проступает «в таких условиях цель придётся урезать» — это откат к реакции нижнего уровня; фиксируй потолок здесь.
- **Примеры:**
  - ✅ «Барьеры: нехватка финансирования, устаревшая технология. Сильные стороны: опытная команда, лояльная база» → L3.
  - ✅ «Мешает регуляторка и слабый бренд; помогает дистрибуция и деньги на счету» → L3.
  - ❌ «Отставание в технологии компенсируем экспертизой команды через [механизм]» → L4: связка есть.

**L4 · Интегрирующая позиция — «ресурс назначен на барьер»**

Вход на уровень — дизъюнкция с обязательным довеском: связка «ресурс Y снимает барьер X» **и/или** классификация ограничений на фиксированные и преодолимые — и в любом случае **назван конкретный механизм** преодоления. Без механизма ни связка, ни классификация уровень не дают. Верхняя граница — по направлению приоритизации: приоритеты строятся от осуществимости («начнём с того, что реально»), а не от цели.

- **ДЕЛАЕТ — обязательные признаки: хотя бы один из первых двух, плюс третий обязателен.**
  1. Связка «ресурс → барьер». Засчитывается: явное назначение ресурса на преодоление конкретного барьера — «экспертиза команды компенсирует отставание в технологии через…».
  2. Классификация ограничений. Засчитывается: функциональное различение — фиксированные (строим стратегию с их учётом) против преодолимых (снимаем механизмом), влияющее на реакцию. Не засчитывается: ярлык «это сложное ограничение».
  3. Названный механизм. Засчитывается: партнёр, канал, компенсация компетенцией, конкретный ход. Не засчитывается: «всё преодолимо, найдём способ».
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Поиск обходных путей. На барьер отвечает «как преодолеть», а не «уменьшить цель».
  - Цель амбициозна, меняется путь. Ограничение перекраивает маршрут, но не цель.
  - Узкое место названо явно.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** приоритеты должны строиться от цели (ограничение становится первой задачей, потому что без него цель недостижима) и/или должна быть поставлена под вопрос сама категория «непреодолимого».
- **НЕ ТРЕБУЕТСЯ:** переворот ограничения в преимущество; полнота перечня ограничений.
- **Дисквалификаторы:**
  - **«Преодолел на словах».** «Всё преодолимо, найдём способ» без механизма — декларация, признак 3 не открыт.
  - **Классификация как ярлык.** «Это сложное ограничение» функциональным различением не является.
- **Примеры:**
  - ✅ «Нехватка финансирования — преодолимое: привлекаем партнёра. Регуляторные барьеры — фиксированные: закладываем в стратегию. Отставание в технологии компенсируем экспертизой команды через [механизм]» → L4.
  - ❌ «Ограничений много, но мы всё преодолеем» → L2: механизма нет, диагностики нет.
  - ❌ «Регуляторный барьер все считают непреодолимым; кто решит его первым через [механизм], получит рынок — делаем это первой задачей» → L5.

**L5 · Проектирующая позиция — «ограничение как первая задача»**

Вход на уровень — дизъюнкция: достаточно одного из двух признаков, но каждый обязательно с конкретным механизмом. Без механизма ни один из них не засчитывается: бравада «нас ничто не остановит» уровень не открывает, а при отсутствии диагностики барьеров вовсе — понижай вплоть до реактивной позиции. Ограничений сверху нет.

- **ДЕЛАЕТ — обязательные признаки, хотя бы один из двух, каждый с механизмом.**
  1. Приоритет от цели. Засчитывается: «цель остаётся [амбициозной]; главное ограничение — X; это не повод менять цель, а первая задача: снимем X через [механизм] — остальной путь открывается». Не засчитывается: «начнём с того, что реально» — это приоритет от осуществимости.
  2. Пересмотр категории ограничения. Засчитывается: «принято считать X фиксированным, но при [условии/механизме] он преодолим». Не засчитывается: сомнение без названного условия или механизма.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Переворот ограничения в преимущество — через конкретный механизм, не через риторику.
  - Ограничение встроено в план как объект работы с приоритетом, заданным целью.
- **НЕ ДЕЛАЕТ:** ограничений сверху нет.
- **Дисквалификаторы:**
  - **«Всё преодолимо»** — главная ловушка. Бравада без механизма уровень не открывает; при отсутствии диагностики барьеров — понижай вплоть до L2.
  - **Риторический переворот.** «Наша слабость — на самом деле сила!» без конкретного механизма — лозунг.
- **Примеры:**
  - ✅ «Регуляторный барьер все считают непреодолимым, поэтому в сегмент никто не идёт. Значит, кто решит его первым через [механизм], получит рынок — делаем это первой задачей» → L5: признаки 1 и 2 с механизмом.
  - ✅ «Дефицит кадров — не потолок, а причина построить [модель], которой у конкурентов нет; ограничение становится нашим отличием через [механизм]» → L5.
  - ❌ «Ограничения серьёзные, но мы настроены решительно» → L2.

### АК-1 · Широта охвата факторов среды

**Навык:** Анализ контекста (АК)
**Тип прогрессии:** наращивание (А)

**Что измеряет:** ширину поля зрения при анализе внешней среды — какие домены замечены и учтены. Оценивается **охват и досягаемость скана**, а не то, что с факторами сделано.

**Счётная единица — домен.** Домен — категория факторов среды: конкуренты, регуляторика, технологии, макроэкономика, поведение клиентов, поставщики и цепочки, соц-демография, геополитика, смежные отрасли и так далее. **Считаются домены, а не факторы:** два конкурента — один домен, ширины не прибавляют. Отдельно различаются:

- **фактор из кейса** — прямо названный в материалах либо пересказанный другими словами;
- **фактор за пределами кейса** — которого в тексте нет: выведен логически, принесён из внешнего знания, либо получен как нетривиальный, нигде прямо не сказанный вывод из материалов или как предложенное участником действие;
- **слабый сигнал** — правдоподобный и релевантный, но не акцентированный ни в кейсе, ни в «здравом смысле» отрасли фактор, который большинство пропустит.

**Стены.**

- **От АК-2** — главная стена способности. Объяснение того, как один фактор влияет на другой или на компанию, здесь **не засчитывается и уровень не поднимает**. Для этой способности засчитывается только сам факт, что фактор замечен и вошёл в картину. Богатая причинная модель на узком наборе факторов = высокий АК-2 при низком АК-1.
- **От МК-2.** Построение образа будущего из факторов — МК-2. Здесь считается сам скан.
- **От ПП-2.** Переосмысление факторов как барьеров и enablers относительно цели — ПП-2.

**Лестница гейтов.**

| Гейт | Условие |
|------|---------|
| **G2** | Назван хотя бы один конкретный внешний фактор (а не настроение «рынок сложный»). |
| **G3** | Покрыто ≥2 разных домена. |
| **G4** | В картину добавлен хотя бы один фактор за пределами кейса. |
| **G5** | Скан досягает до слабых сигналов или неочевидных, удалённых доменов, не акцентированных ни в кейсе, ни в «здравом смысле» отрасли. |

**L1 · Не проявлено**

Вход на уровень — по отсутствию: во всём ответе не назван ни один **конкретный** внешний фактор. Настроение («рынок сложный», «времена тяжёлые») фактором не является. Достаточно одного конкретного фактора, функционально использованного в рассуждении, чтобы этот уровень не ставить.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Ни одного конкретного внешнего фактора. Рассуждение опирается только на внутренние данные компании; внешнее если и всплывает, то как фон и в рассуждении не используется.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Только внутрь. Продукт, команда, процессы, продажи — всё «про нас», без взгляда наружу.
  - Случайное внешнее. «Рынок сложный» как фон, без конкретики.
  - Контекст кейса проигнорирован. Разделы про среду не вошли в ответ вовсе.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** достаточно одного конкретного внешнего фактора. «Растёт конкуренция» — следующий уровень; «рынок сложный» — этот.
- **Ложное понижение (не занижай):** детальный разбор внутренней кухни признаком этого уровня не является — богатство внутренней картины здесь вообще не предмет оценки. Один функционально использованный внешний фактор поднимает.
- **Примеры:**
  - ✅ «Нужно улучшить продукт, нанять разработчиков и поднять продажи» → L1: среда не в поле зрения.
  - ✅ «Рынок непростой, но справимся» → L1: настроение вместо фактора.
  - ❌ «На рынке растёт конкуренция» → L2.

**L2 · Единичный элемент — «один громкий фактор»**

Вход на уровень — один обязательный признак: назван конкретный внешний фактор. Верхняя граница — по счёту доменов: всё внешнее в ответе принадлежит **одному** домену. Развёрнутость обсуждения этого фактора значения не имеет — глубина здесь не предмет.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Конкретный внешний фактор из одного домена. Засчитывается: фактор, поданный в кейсе крупно (главная угроза или тренд), названный конкретно. Не засчитывается: настроение, оценка обстановки без предмета.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Самое заметное. Взят фактор, который невозможно не заметить.
  - Один домен. Всё внешнее — из одной категории: только конкуренты или только регуляторика.
  - Два фактора внутри одного домена. «Два конкурента» — ширины не прибавляют.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужно покрытие ≥2 разных доменов. Счёт идёт по доменам, а не по факторам.
- **НЕ ТРЕБУЕТСЯ:** объяснение значимости фактора — это АК-2 и здесь не требуется.
- **Дисквалификаторы:**
  - **«Много слов об одном».** Развёрнутое обсуждение одного фактора уровень не поднимает: широта — охват доменов, а не глубина проработки одного.
- **Примеры:**
  - ✅ «На рынке растёт конкуренция» → L2.
  - ✅ «Главное — новый регулятор» → L2.
  - ❌ «Конкуренция усиливается, спрос смещается в цифру, регулятор ужесточает требования» → L3: три домена.

**L3 · Множественные элементы — «поверхностная широта»**

Вход на уровень — один обязательный признак: покрыто ≥2 разных домена. Верхняя граница — по источнику: все факторы взяты из того, что прямо названо в кейсе. Число таких факторов роли не играет: пять аккуратно переписанных из кейса факторов остаются здесь.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Покрытие ≥2 разных доменов. Засчитывается: конкуренты **и** тренды, регуляторика, технологии или поведение клиентов — разные категории. Не засчитывается: несколько факторов внутри одной категории.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Системность перечисления. Домены названы не случайно, а как осознанный обзор среды.
  - В границах кейса. Все факторы — из явно обозначенного в тексте.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужен хотя бы один фактор за пределами кейса — выведенный логически, принесённый извне, либо полученный как нетривиальный, нигде прямо не сказанный вывод или как предложенное участником действие.
- **НЕ ТРЕБУЕТСЯ:** связи между факторами (АК-2); полнота охвата.
- **Дисквалификаторы:**
  - **Эхо кейса** — главная ловушка способности. Пересказ подсвеченного кейсом — это чтение, а не скан. Потолок для эха кейса — этот уровень, независимо от количества.
  - **«Широта = длина списка».** Объём перечня уровень не поднимает.
  - **Пересказ другими словами.** Тот же факт кейса в иной формулировке границу не открывает.
- **Примеры:**
  - ✅ «Конкуренция усиливается, спрос смещается в цифру, регулятор ужесточает требования» — все три из кейса → L3.
  - ❌ «Помимо названного в кейсе, тут неизбежно появятся поставщики сырья и демографический сдвиг спроса» → L4.

**L4 · Интегрированная картина — «скан выходит за пределы кейса»**

Вход на уровень — один обязательный признак: в картину добавлен хотя бы один фактор за пределами кейса. Широкое покрытие (≈4+ доменов) — признак того же уровня, но **условием границы не является**: при факторе извне и узком покрытии ставится этот уровень с пометкой для ручной проверки. Верхняя граница — по досягаемости: до слабых сигналов и удалённых доменов скан не дотягивается.

Здесь и выше «интегрированная» и «системная» означают полноту и досягаемость скана, а не причинную интеграцию факторов: последняя целиком относится к смежной способности и здесь не засчитывается.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Фактор за пределами кейса. Засчитывается: «здесь неизбежно всплывёт [домен], хотя в кейсе про это не сказано»; фактор из внешнего знания; нетривиальный, нигде прямо не сказанный вывод из материалов; предложенное участником действие или решение. Не засчитывается: пересказ факта кейса другими словами.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Широкое покрытие. ≈4+ доменов, включая менее очевидные: поставщики, соц-демография, смежные отрасли.
  - Микроуровень. Замечен не только макротренд, но и более тонкие проявления внутри домена.
  - Регистрация напряжений. Отмечено, что факторы могут конфликтовать («регуляторика ужесточается, а спрос растёт — это в противофазе») — как факт сосуществования, без разбора механизма.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** скан должен досягать до слабых сигналов или неочевидных, удалённых доменов, не акцентированных ни в кейсе, ни в «здравом смысле» отрасли.
- **НЕ ТРЕБУЕТСЯ:** механизм влияния факторов друг на друга — это АК-2; причинная интеграция здесь не засчитывается.
- **Дисквалификаторы:**
  - **Стена от АК-2** — главная ловушка уровня. Если участник объясняет, как один фактор влияет на другой, и выстраивает цепочку последствий, это признак другой способности: здесь он уровень не поднимает.
  - **Пересказ кейса.** Границу не открывает ни при каком объёме.
- **Примеры:**
  - ✅ «Помимо названного в кейсе, тут неизбежно появятся поставщики сырья и демографический сдвиг спроса — их в тексте нет, но они логически следуют из ситуации» → L4.
  - ✅ «Регуляторное ужесточение и рост конкуренции идут одновременно — эти два фактора в противофазе» → L4: регистрация напряжения без механизма.
  - ❌ «Пять факторов, все из кейса» → L3.

**L5 · Системная картина — «скан достаёт до фронтира»**

Вход на уровень — один обязательный признак: в поле зрения вошёл слабый сигнал или удалённый, неочевидный домен, не акцентированный ни в кейсе, ни в «здравом смысле» отрасли. Причинная интеграция по-прежнему не требуется: соединение факторов в систему относится к смежной способности. Ограничений сверху нет.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Слабый сигнал или удалённый домен. Засчитывается: ранний, ещё не проявившийся фактор («есть ранний признак [X], который пока не виден в отраслевых обзорах»); фактор из смежной или далёкой области, которую обычно не связывают с этой ситуацией; то, что не акцентировано ни в кейсе, ни в отраслевом здравом смысле. Не засчитывается: экзотический фактор, притянутый без основания («а вдруг астероид») — это шум, а не слабый сигнал.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Поле зрения шире типового: в картину входит то, что большинство участников не замечает вовсе.
  - Формулировка «я бы держал в поле зрения…» применительно к тому, чего в кейсе нет.
- **НЕ ДЕЛАЕТ:** ограничений сверху нет.
- **Дисквалификаторы:**
  - **Стена от АК-2** — главная ловушка уровня. Самоусиливающийся контур, петли обратной связи, эффекты второго порядка — это АК-2, а не здесь.
  - **Эффектная догадка.** Слабый сигнал засчитывается, когда он правдоподобен и релевантен ситуации, просто неочевиден.
- **Примечание к проверке зависимости:** этот уровень означает, что в поле зрения вошёл очень широкий и неочевидный набор. Он служит потолком для АК-2, но не гарантирует высокого АК-2: заметить много не значит глубоко проанализировать. Обратное запрещено — АК-2 выше АК-1 даёт флаг ручной проверки (§9.6).
- **Примеры:**
  - ✅ «Помимо очевидного — я бы держал в поле зрения ранний сдвиг в структуре занятости и регуляторную инициативу в смежной отрасли: в кейсе их нет, но это факторы, которые скоро станут значимыми» → L5.
  - ✅ «Слабый сигнал, который здесь легко пропустить, — изменение поведения не наших, а соседних по рынку клиентов» → L5.
  - ❌ «Помимо кейса, добавлю поставщиков и демографию» → L4: фактор извне есть, фронтира нет.

### АК-2 · Глубина анализа взаимосвязей

**Навык:** Анализ контекста (АК)
**Тип прогрессии:** наращивание (А)

**Что измеряет:** качество когнитивной работы с уже замеченными факторами — от присвоения ярлыка до системной модели с петлями. Число замеченных факторов здесь не оценивается.

**Счётная единица — раскрытая связь.** Различаются четыре формы, и они не взаимозаменяемы:

- **ярлык** — качественная оценка фактора без объяснения: «угроза», «возможность», «риск», «важно»;
- **механизм влияния** — «фактор → [как именно действует] → следствие для компании»;
- **цепочка между факторами** — «фактор A меняет фактор B», минимум два перехода (A→B→C);
- **петля** — контур, где влияние возвращается на более ранний элемент.

**Стены.**

- **От АК-1.** Здесь не оценивается, сколько факторов замечено. Петлю можно построить на трёх факторах — это высокий уровень здесь при узком охвате.
- **От МК-2.** Цепочка последствий текущих факторов — здесь. Построение качественно иного будущего состояния или сценария — МК-2. «Рост рынка через 2 года привлечёт игроков» — эффект второго порядка, а не образ будущего.
- **От ПР.** «Рекомендации вытекают из анализа» здесь — свидетельство, что анализ несущий, а не декоративный. Качество самого приоритета или выбора — ПР, здесь не оценивается.

**Протокол изоляции.** Эта способность оценивается **в изоляции**, без сверки с АК-1. Ограничение АК-2 ≤ АК-1 проверяется постфактум и при нарушении даёт флаг ручной проверки, а не понижение (§9.6). Известное законное срабатывание: глубокий контур, свитый из трёх факторов кейса (узкий охват, большая глубина) — допустимый случай; флаг здесь означает «убедись, что глубина не приписана незамеченным факторам», а не ошибку участника.

**Лестница гейтов.**

| Гейт | Условие |
|------|---------|
| **G2** | Хотя бы одному фактору присвоен качественный ярлык. |
| **G3** | Раскрыт конкретный механизм влияния хотя бы одного фактора («это означает, что…»). |
| **G4** | Есть хотя бы одна цепочка между двумя и более факторами **И** рекомендации наблюдаемо вытекают из анализа. |
| **G5** | Идентифицирована хотя бы одна замкнутая петля, обратная связь или точка нестабильности. |

**L1 · Не проявлено**

Вход на уровень — по отсутствию оценочного слоя: ни одному фактору не присвоена даже качественная оценка. Факторы перечислены — и сразу следует рекомендация, без промежуточного шага «что это значит». Достаточно одного ярлыка, чтобы этот уровень не ставить.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Ни одного качественного ярлыка. Ни один фактор не назван ни угрозой, ни возможностью, ни риском, ни важным — оценочный слой отсутствует целиком.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Факт → рекомендация напрямую. «Есть конкуренты — надо усилить продукт», без шага «что это значит».
  - Голое перечисление. Факторы названы списком, ни один не оценён даже как хороший или плохой для компании.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** достаточно присвоить хотя бы одному фактору качественный ярлык — «это угроза», «это возможность», «это риск».
- **Ложное понижение (не занижай):** если фактор назван угрозой или возможностью, это уже следующий уровень, даже без объяснения. Отсутствие механизма — граница между следующими двумя уровнями, а не признак этого.
- **Примеры:**
  - ✅ «На рынке есть конкуренты, клиенты, технологии. Нужно развивать продукт» → L1.
  - ❌ «Выход конкурента — серьёзная угроза» → L2.

**L2 · Единичный элемент — «ярлык без мостика»**

Вход на уровень — один обязательный признак: хотя бы одному фактору присвоен качественный ярлык. Верхняя граница — по отсутствию механизма: не сказано, **как именно** фактор действует на компанию. Длина и эмоциональность обоснования значимости на уровень не влияют.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Качественный ярлык. Засчитывается: «угроза», «возможность», «важно», «риск», «критично» применительно к конкретному фактору. Не засчитывается: упоминание фактора без всякой оценки.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Одношаговость. Присвоением категории всё и заканчивается, следствие не разворачивается.
  - Драматизация. Ярлык усилен эмоцией («это критично!»), но механизма по-прежнему нет.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужно раскрыть конкретный механизм влияния хотя бы одного фактора. «Угроза» — этот уровень; «угроза, потому что переманит наших крупных клиентов, а на них 60% выручки» — следующий.
- **НЕ ТРЕБУЕТСЯ:** широта охвата (это АК-1); связи между факторами.
- **Дисквалификаторы:**
  - **Красноречивый ярлык** — главная ловушка. Длинное эмоциональное обоснование, почему фактор важен, без объяснения, как он действует на компанию, остаётся здесь. Насыщенность текста не равна глубине анализа.
- **Примеры:**
  - ✅ «Выход конкурента — угроза. Рост рынка — возможность. Рекомендую сосредоточиться на продукте» → L2.
  - ❌ «Угроза, потому что переманит наших крупных клиентов, а на них 60% выручки» → L3.

**L3 · Множественные элементы — «механизм влияния на компанию»**

Вход на уровень — один обязательный признак: раскрыт конкретный механизм влияния хотя бы одного фактора на путь или цель компании. Верхняя граница — по адресату связи: факторы разбираются параллельно, каждый со своим следствием **для компании**; связей между самими факторами нет.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Механизм влияния. Засчитывается: не «угроза», а «угроза, потому что [механизм] → [следствие для компании]». Не засчитывается: ярлык; эмоциональное обоснование важности.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Несколько факторов, каждый со своим следствием. Разбор идёт по факторам параллельно.
  - Одношаговые связи «A → B». Один фактор — одно следствие для компании.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужны оба признака вместе — связь между самими факторами («A меняет B») и наблюдаемое следование рекомендаций из анализа.
- **НЕ ТРЕБУЕТСЯ:** охват факторов (это АК-1); петли; вероятностные оценки.
- **Дисквалификаторы:**
  - **«Список следствий = цепочка»** — главная ловушка. Три раздельных «фактор → следствие для компании» — это три параллельных разбора этого уровня, а не цепочка. Связь требуется **между факторами**.
- **Примеры:**
  - ✅ «Рост конкуренции → надо ускорить вывод продукта. Регуляторика → потребует инвестиций. Сдвиг предпочтений → открывает возможность» → L3.
  - ❌ «Рост рынка → приток игроков → передел каналов» → L4: связь между факторами.

**L4 · Интегрированная картина — «цепочка между факторами»**

Вход на уровень — конъюнкция двух признаков: цепочка между двумя и более факторами (минимум два перехода, A→B→C) **и** наблюдаемое следование рекомендаций из этой цепочки. Верхняя граница — по форме связи: цепочки линейны, замкнутых петель и обратных связей нет.

- **ДЕЛАЕТ — обязательные признаки, оба.**
  1. Фактор влияет на фактор. Засчитывается: «рост рынка → приток игроков → передел каналов» — звенья связаны между собой, минимум два перехода. Не засчитывается: несколько параллельных «фактор → следствие для компании».
  2. Анализ ведёт к решению. Засчитывается: рекомендация выведена из цепочки. Не засчитывается: рекомендация, приклеенная к анализу без связи с ним.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Эффекты второго порядка. Не «рынок растёт», а что этот рост запускает дальше.
  - Многозвенность. Цепочка длиннее двух переходов.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужна хотя бы одна замкнутая петля, обратная связь или названная точка нестабильности.
- **НЕ ТРЕБУЕТСЯ:** широта охвата (это АК-1); качество самого приоритета (это ПР).
- **Дисквалификаторы:**
  - **Стена от МК-2.** Построение качественно иного будущего состояния — МК-2, здесь не засчитывается.
  - **Длина вместо замыкания.** Сколь угодно длинная линейная цепочка остаётся здесь.
- **Примеры:**
  - ✅ «Регуляторика → выше порог входа → игроки будут крупными → ценовая конкуренция неизбежна → стратегия не на цене» → L4: оба признака.
  - ❌ «Рост рынка → приток игроков → передел каналов» без единого решения из этого → L3: признак 2 отсутствует.
  - ❌ «…маржа падает → меньше R&D → слабее продукт → снова падает маржа» → L5: контур замкнут.

**L5 · Системная картина — «замкнутый контур»**

Вход на уровень — один обязательный признак: прослежена замкнутая петля, обратная связь или названа точка нестабильности. «Прослежена» означает явно показанный возврат влияния на более ранний элемент; слово «система» без такого контура признаком не является. Ограничений сверху нет.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Замкнутый контур, обратная связь или точка нестабильности. Засчитывается: «…→ маржа падает → меньше R&D → слабее продукт → снова падает маржа» — влияние вернулось на более ранний элемент; либо назван порог или перегиб, где система резко меняет поведение. Не засчитывается: линейная цепочка, названная «петлёй», но не замыкающаяся на вход.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Тип контура назван: усиливающий (разгоняется) или гасящий (стабилизируется).
  - Сетевой взгляд. Кто на кого влияет в системе, где узлы и рычаги.
  - Стратегия как позиционирование в системе: «выйти из петли», «сместить точку равновесия».
- **НЕ ДЕЛАЕТ:** ограничений сверху нет.
- **Дисквалификаторы:**
  - **Псевдопетля** — главная ловушка. Длинная цепочка A→B→C→D, названная петлёй, но не возвращающаяся на вход, остаётся предыдущим уровнем.
  - **«Системные слова».** «Система», «синергия», «экосистема», «всё взаимосвязано» без конкретно прослеженного контура — лексика, не признак.
  - **Стена от АК-1.** Широкая сеть факторов сама по себе — это охват, а не глубина.
- **Примеры:**
  - ✅ «Усиливающая петля: цифровизация → ниже барьеры → больше игроков → ценовая война → падает маржа → меньше R&D → слабее дифференциация → снова ценовая война. Точка нестабильности — маржа ниже порога инвестиций в качество. Стратегия — вывести компанию из этой петли» → L5.
  - ❌ «Здесь всё взаимосвязано, это единая экосистема» → уровень определяется по фактически раскрытым связям, лексика его не задаёт.

### ПР-1 · Выделение важного и расстановка приоритетов

**Навык:** Приоритизация (ПР)
**Тип прогрессии:** наращивание (А)

**Что измеряет:** результат селекции — сколько приоритетов, насколько они конкретны, есть ли явные отказы и что эти отказы высвобождают. Почему выбрано именно это — предмет ПР-2 и здесь не оценивается.

**Счётная единица — приоритет и отказ.** Различаются:

- **маркер селекции** — «главное», «в первую очередь», «прежде всего» — выделение без отсечения;
- **явный отказ** — названная опция, от которой отказываются: «не делаем гео-экспансию». «Сфокусируемся на главном» отказом не является;
- **измеримый ориентир** — проверяемая цель на приоритет: «30% recurring за 18 мес». «Вырастем значительно, процентов на 30» — декоративное число, не ориентир;
- **высвобождаемый ресурс** — что именно освобождает отказ: «3 продавца и ~$200K»;
- **правило отказа** — принцип отсечения, применимый к ещё не возникшим инициативам;
- **граничное условие** — заранее заданный порог успеха или провала, работающий как триггер пересмотра. «Будем следить и при необходимости пересмотрим» триггером не является.

**Стены.**

- **От ПР-2.** Здесь оценивается **что** выбрано и от чего отказались. Основание выбора и его устойчивость — ПР-2.
- **От ПП-2.** Там объект приоритизации — ограничения и ресурсы; здесь — инициативы и направления.

**Лестница гейтов.**

| Гейт | Условие |
|------|---------|
| **G2** | Есть хотя бы один маркер селекции. |
| **G3** | Зафиксирован хотя бы один явный отказ. |
| **G4** | Есть приоритет с измеримым ориентиром **И** отказ с указанием высвобождаемого ресурса. |
| **G5** | Есть отказ как обобщающее правило **и/или** приоритеты с граничными условиями-триггерами. |

**L1 · Не проявлено**

Вход на уровень — по отсутствию селекции: в ответе нет ни одного маркера выделения, всё перечисленное равнозначно. Число пунктов равно числу найденных проблем. Длина списка тянет вниз, а не вверх: пятнадцать «приоритетов» — это отсутствие приоритизации, а не богатый набор.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Ни одного маркера селекции. Во всём ответе ничего не выделено как главное, ничего не отсечено, задачи равнозначны.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Перечисляет всё «что нужно», без фильтрации.
  - Формулировки общие, задачи одного порядка.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** достаточно одного маркера селекции — «главное», «в первую очередь».
- **Дисквалификаторы:**
  - **«Длинный список = приоритизация»** — главная ловушка. Объём перечня уровень не поднимает.
- **Примеры:**
  - ✅ «Нужно: улучшить продукт, нанять людей, выйти на рынки, оптимизировать процессы, усилить маркетинг» → L1: всё на одном уровне.
  - ❌ «Главное — продукт. Также важно: каналы, клиенты, найм» → L2.

**L2 · Единичный элемент — «главное есть, отсечения нет»**

Вход на уровень — один обязательный признак: есть маркер селекции. Верхняя граница — по отсутствию отказа: ни одна опция явно не отброшена. Список «также важно» означает, что не отсечено ничего, — уровень остаётся здесь, как бы ярко ни было выделено «главное».

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Маркер селекции. Засчитывается: «главное — X», «в первую очередь — Y». Не засчитывается: перечень без выделения.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Названо много направлений (5–7 и больше), из них выделено «главное».
  - Ограничение по числу приоритетов не зафиксировано.
  - Конструкция «также важно», «не менее важно».
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужен хотя бы один явный отказ — названная опция, от которой отказываются.
- **НЕ ТРЕБУЕТСЯ:** метрики, обоснование выбора (это ПР-2).
- **Дисквалификаторы:**
  - **«Также важно»** — главная ловушка. Признак того, что не отсечено ничего.
- **Примеры:**
  - ✅ «Главное — продукт. Также важно: каналы, клиенты, найм…» → L2.
  - ❌ «Три приоритета: подписка, B2B, автоматизация. Не делаем гео-экспансию» → L3.

**L3 · Множественные элементы — «узкий набор и явные отказы»**

Вход на уровень — один обязательный признак: зафиксирован хотя бы один явный отказ. Ограниченность набора (3–5 приоритетов) — типичная форма уровня, а не условие входа. Верхняя граница — по отсутствию двух вещей сразу: измеримых ориентиров на приоритеты и указания, что высвобождает отказ.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Явный отказ. Засчитывается: названная опция, от которой отказываются, — «не делаем гео-экспансию», «отказываемся от нового продуктового направления». Не засчитывается: «сфокусируемся на главном», «остальное потом» — это не отказ, а перефразированное выделение.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Ограниченный набор: 3–5 приоритетов.
  - Видно, что рассмотрено больше, чем выбрано.
  - Приоритеты — направления без метрик.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужны оба признака вместе — приоритет с измеримым ориентиром и отказ с названным высвобождаемым ресурсом.
- **НЕ ТРЕБУЕТСЯ:** правила отсечения, триггеры пересмотра.
- **Дисквалификаторы:**
  - **Псевдо-отказ.** «Сфокусируемся на главном» отказом не является: нужна названная отброшенная опция.
- **Примеры:**
  - ✅ «Три приоритета: подписка, B2B, автоматизация. Не делаем: гео-экспансию, новое продуктовое направление» → L3.
  - ❌ «Приоритет — подписка, 30% recurring за 18 мес. Отказ от B2B-пилота освобождает 3 продавцов и ~$200K» → L4.

**L4 · Интегрированная картина — «метрики и ресурсные отказы»**

Вход на уровень — конъюнкция двух признаков: приоритет с измеримым ориентиром **и** отказ с указанием высвобождаемого ресурса. Верхняя граница — по форме: набор остаётся конкретным перечнем, логика отбора не превращена в правило, граничных условий-триггеров нет.

- **ДЕЛАЕТ — обязательные признаки, оба.**
  1. Измеримый ориентир на приоритет. Засчитывается: проверяемая цель — «30% recurring за 18 мес», «200K юзеров к Q3». Не засчитывается: число, приклеенное к направлению и непроверяемое, — «вырастем значительно, процентов на 30».
  2. Отказ с высвобождаемым ресурсом. Засчитывается: «отказ от B2B-пилота освобождает 3 продавцов и ~$200K на приоритет 1». Не засчитывается: отказ без указания, что он даёт.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Приоритеты — конкретные действия, а не направления.
  - Выбранное и отвергнутое сопоставимы по масштабу.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужен отказ как обобщающее правило и/или приоритеты с заранее заданными граничными условиями, работающими как триггеры пересмотра.
- **НЕ ТРЕБУЕТСЯ:** обоснование выбора (это ПР-2); полнота набора.
- **Дисквалификаторы:**
  - **Декоративная метрика.** Число, не являющееся проверяемой целью, признак 1 не открывает.
- **Примечание к границе наверх:** это самая тонкая граница во всём наборе; при калибровке ожидаемо более низкое согласие оценщиков. Правило разрешения: при слабо выраженных верхних маркерах (правило-принцип и/или преднастроенные триггеры прочитываются неуверенно) ставится **этот** уровень с флагом «стремится к верхнему» — флаг идёт на ручную сверку и балла не меняет.
- **Примеры:**
  - ✅ «(1) Подписка — 30% recurring за 18 мес. (2) Интеграция с Z — 200K юзеров к Q3. Отказ: B2B-пилот → освобождает 3 продавцов и ~$200K на приоритет 1» → L4.
  - ❌ «Три приоритета и два отказа», без метрик и без высвобождаемых ресурсов → L3.

**L5 · Системная картина — «правила и триггеры»**

Вход на уровень — дизъюнкция: достаточно одного признака из двух. Оба должны быть обобщающими или преднастроенными: правило, описывающее ровно уже сделанные отказы, и намерение «следить и при необходимости пересмотреть» входным условием не являются. Ограничений сверху нет.

- **ДЕЛАЕТ — обязательные признаки, хотя бы один из двух.**
  1. Отказ как правило. Засчитывается: принцип отсечения, применимый к ещё не возникшим инициативам, — «любая инициатива >1 FTE или >$50K, не ускоряющая приоритет, отклоняется». Не засчитывается: правило, описывающее ровно уже сделанные отказы и не обобщающее на новые случаи.
  2. Граничные условия как триггеры. Засчитывается: заранее заданный порог, который «выстреливает», — «успех ≥25%; провал <15% к мес. 6 — триггер пересмотра». Не засчитывается: «будем следить и при необходимости пересмотрим».
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Набор приоритетов образует замкнутую самотестирующуюся систему.
  - Приоритеты и отказы читаются как decision rules.
- **НЕ ДЕЛАЕТ:** ограничений сверху нет.
- **Дисквалификаторы:**
  - **Псевдо-триггер.** Намерение следить порогом не является.
  - **Правило постфактум.** Перечень уже сделанных отказов в форме правила — предыдущий уровень.
- **Примеры:**
  - ✅ «Приоритет 1: 30% recurring за 18 мес. Успех ≥25%. Провал <15% к мес. 6 — триггер пересмотра. Правило отказа: любая инициатива >1 FTE или >$50K, не ускоряющая приоритет, отклоняется» → L5: оба признака.
  - ❌ «Правило: не делаем гео-экспансию и не делаем B2B» → L4: это перечень уже сделанных отказов.

### ПР-2 · Обоснование стратегического выбора

**Навык:** Приоритизация (ПР)
**Тип прогрессии:** замещение (Б)

**Что измеряет:** основание выбора и его устойчивость под давлением — на чём стоит выбор и что с ним происходит при новой или противоречащей информации. Что именно выбрано — предмет ПР-1 и здесь не оценивается.

**Две оси:**

- **основание** — реакция → интуиция → фильтр по цели → trade-off между инициативами → фильтр для любого решения;
- **устойчивость** — наблюдается только через реакцию на **стресс-тест**: вброшенную в вопросе новую или противоречащую информацию.

**Потолок наблюдаемости.** Если стресс-теста в материале нет, устойчивость ненаблюдаема: оценка ставится по оси «основание», в справку идёт пометка «устойчивость ненаблюдаема», и **потолок — L3**. Верхние два уровня определены через удержание выбора под давлением и без наблюдаемого стресс-теста недостижимы (§9.7).

**Счётная единица — реакция на стресс-тест.** Различаются четыре реакции, и они не взаимозаменяемы:

- **сброс** — предыдущие рекомендации брошены, набор собран заново;
- **дописывание** — новое добавлено пунктом, старое не пересмотрено;
- **отступление** — новое соотнесено с целью, но сам выбор всё же сменился;
- **удержание** — выбор сохранён по существу, меняется «как», а не «что».

**Стены.**

- **От ПР-1.** Здесь — почему и насколько устойчиво. Что выбрано — ПР-1. Блестящее обоснование рыхлого набора даёт флаг (§9.6).
- **От ПП-2.** Там — работа с ограничениями на пути (барьер, ресурс). Здесь — устойчивость обоснования выбора при новой информации.
- **От МК-2.** Сценарии здесь — это условия устаревания выбора (когда пересмотреть приоритет), а не конструирование будущих миров.

**Протокол изоляции.** Эта способность оценивается в изоляции, без сверки с ПР-1. Ограничение ПР-2 ≤ ПР-1 + 1 проверяется постфактум и даёт флаг, а не понижение. Допуск «+1» мягче строгого ограничения в АК: обосновать выбор можно чуть изощрённее, чем выглядит сам результат селекции; расхождение больше чем на уровень — сигнал проверить, не приписано ли обоснование выбору, которого фактически нет.

**Лестница гейтов.**

| Гейт | Условие |
|------|---------|
| **G2** | Есть обоснование, привязанное хотя бы к информации из кейса (пусть интуитивное). |
| **G3** | Выбор обоснован привязкой к сформулированной стратегической цели (а не к «важности»). |
| **G4** | Инициативы сравниваются между собой (trade-off) **И** выбор удержан под стресс-тестом. |
| **G5** | Приоритеты фильтруют решения за пределами стратегического контекста (операционные тоже) **и/или** заданы заранее условия устаревания выбора. |

**L1 · Не проявлено**

Вход на уровень — по отсутствию основания: решения определяются срочностью момента, ни один критерий не сформулирован, связи «анализ → рекомендация» нет. Под стресс-тестом предыдущие рекомендации бросаются, набор собирается с нуля.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Ни одного обоснования. Выбор определяется тем, «что горит сейчас»; ни критерия, ни привязки к информации из кейса не названо.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Реакция на срочность момента.
  - Под стресс-тестом — сброс: другой набор с нуля.
  - Рекомендации не следуют ни из какого анализа.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** достаточно обоснования, привязанного к информации из кейса, — пусть интуитивного.
- **Примеры:**
  - ✅ «Нанять маркетолога, обновить сайт, запустить рекламу» — без привязки; под стресс-тестом другой набор с нуля → L1.
  - ❌ «Очевидно, нужно удержание — отток 15% это много» → L2.

**L2 · Реактивная позиция — «интуитивное основание»**

Вход на уровень — один обязательный признак: обоснование привязано к информации из кейса. Верхняя граница — по типу привязки: основание идёт от «важности» и «очевидности», а не от сформулированной стратегической цели. Развёрнутость и уверенность формулировки уровень не поднимают.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Обоснование, привязанное к информации из кейса. Засчитывается: «очевидно, нужно удержание — отток 15% это много» — ассоциативная, но привязка. Не засчитывается: выбор по срочности без единой отсылки к материалу.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Обороты «очевидно, что…», «понятно, что…», «кажется важным».
  - Под стресс-тестом — дописывание: «теперь ещё нужно [новое]», старое не пересмотрено.
  - Цель, относительно которой сделан выбор, не сформулирована.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** выбор должен быть обоснован привязкой к сформулированной стратегической цели, а не к важности.
- **НЕ ТРЕБУЕТСЯ:** сравнение вариантов между собой; устойчивость.
- **Дисквалификаторы:**
  - **Обоснование задним числом** — главная ловушка. Уверенное «очевидно, что…» остаётся интуицией, даже если звучит логично и развёрнуто. Риторика уверенности уровень не поднимает.
  - **«Дописал = отреагировал».** Добавить пункт под стресс-тестом — дописывание, а не удержание и не пересмотр.
- **Примеры:**
  - ✅ «Очевидно, нужно удержание — отток 15% это много»; под стрессом «теперь ещё нужно [новое]» → L2.
  - ❌ «Подписка работает на recurring — это наша цель; отказ от B2B не приближает к ней» → L3.

**L3 · Осознанная позиция — «фильтр по цели»**

Вход на уровень — один обязательный признак: выбор обоснован привязкой к сформулированной стратегической цели. Фильтр применяется бинарно, к каждой инициативе отдельно. Верхняя граница — по двум отсутствиям: инициативы между собой не сравниваются, и под давлением выбор не удерживается. Это же — потолок при ненаблюдаемой устойчивости.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Цель как фильтр. Засчитывается: каждый приоритет привязан к стратегической цели — «подписка работает на recurring [цель]; отказ от B2B не приближает к цели». Не засчитывается: привязка к «важности» без названной цели.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Под стресс-тестом соотносит новое с целью, но может отступить.
  - Фильтр бинарный: ведёт к цели или не ведёт, по каждой инициативе отдельно.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужны оба признака вместе — сравнение инициатив между собой (trade-off) и удержание выбора под стресс-тестом.
- **НЕ ТРЕБУЕТСЯ:** триггеры пересмотра; распространение фильтра на операционные решения.
- **Дисквалификаторы:**
  - **«Фильтр есть, но плывёт».** Под давлением участник соотносит с целью, но сам выбор всё же меняет — потолок этот уровень.
  - **Ненаблюдаемая устойчивость.** Если стресс-теста в материале нет, выше этого уровня подняться нельзя.
- **Примеры:**
  - ✅ «Подписка — работает на recurring; отказ от B2B — не приближает к цели»; под стрессом «раз конкурент запустил — может, ускорить B2B…» → L3: фильтр не удержан.
  - ❌ «И подписка, и B2B ведут к росту; выбираю подписку — быстрее time-to-revenue»; под стрессом калибрует «как», не бросает «что» → L4.

**L4 · Интегрирующая позиция — «trade-off и удержание»**

Вход на уровень — конъюнкция двух признаков: сравнение инициатив между собой **и** удержание выбора под стресс-тестом. Удержание считается по существу: сохранился ли сам выбор. Верхняя граница — по охвату и характеру пересмотра: фильтр работает только в стратегическом контуре, пересмотр реактивен, упреждающих триггеров нет.

- **ДЕЛАЕТ — обязательные признаки, оба.**
  1. Trade-off между инициативами. Засчитывается: объяснение, почему одна лучше другой при ограниченных ресурсах, в том числе отказ от «правильной» ради другой «правильной» — «и подписка, и B2B ведут к росту; выбираю подписку — быстрее time-to-revenue, не требует выделенной команды». Не засчитывается: привязка каждой инициативы к цели по отдельности без сопоставления.
  2. Удержание под стресс-тестом. Засчитывается: выбор сохранён по существу, калибруется «как», а не «что». Не засчитывается: смена выбора уверенным тоном; дописывание нового пункта.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Пересмотр реактивный: после того как изменение произошло.
  - Фильтр не распространён на операционные решения.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** приоритеты должны фильтровать решения за пределами стратегического контекста и/или должны быть заранее заданы условия устаревания выбора.
- **НЕ ТРЕБУЕТСЯ:** сценарии будущих миров (это МК-2).
- **Дисквалификаторы:**
  - **«Уверенно устоял = удержал»** — главная ловушка. Решает, сменился ли выбор по существу, а не тон ответа.
- **Примеры:**
  - ✅ «И подписка, и B2B ведут к росту; выбираю подписку — быстрее time-to-revenue, не требует выделенной команды»; под стрессом — калибровка, не отмена → L4.
  - ❌ Тот же trade-off, но под стрессом выбор сменён → L3.

**L5 · Проектирующая позиция — «фильтр для любого решения»**

Вход на уровень — дизъюнкция: достаточно одного признака из двух. Оба должны быть преднастроенными: «буду следить и адаптироваться» ни одного из них не открывает. Ограничений сверху нет.

- **ДЕЛАЕТ — обязательные признаки, хотя бы один из двух.**
  1. Фильтр на операционные решения. Засчитывается: операционные решения прогоняются через стратегический фильтр — «партнёрство принимаем, только если ускоряет приоритет 1 или 2». Не засчитывается: применение фильтра только к стратегическим инициативам.
  2. Заранее заданные условия устаревания выбора. Засчитывается: названо, при каких условиях выбор перестанет быть верным, — «если рынок подписок не растёт — переключаемся, но не раньше 6 мес данных»; под стресс-тестом реакция как на ожидаемую развилку. Не засчитывается: «буду следить и адаптироваться».
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Под стресс-тестом: «это вариант сценария, активирую альтернативу».
  - Проактивный пересмотр вместо реакции постфактум.
- **НЕ ДЕЛАЕТ:** ограничений сверху нет.
- **Дисквалификаторы:**
  - **Проактивность на словах.** «Буду следить и адаптироваться» — не преднастроенный триггер.
  - **Стена от МК-2.** Построение образа иного будущего — МК-2; заданный триггер пересмотра приоритета — здесь.
- **Примеры:**
  - ✅ «Операционный тест: партнёрство принимаем, только если ускоряет приоритет 1/2. Сценарий пересмотра: если рынок подписок не растёт — переключаемся, но не раньше 6 мес данных» → L5: оба признака.
  - ❌ «Буду отслеживать рынок и при необходимости поменяю приоритеты» → L4: преднастроенного условия нет.

### ГА-1 · Самостоятельная генерация альтернатив

**Навык:** Генерация стратегических альтернатив (ГА)
**Тип прогрессии:** расширение (В)

**Что измеряет:** два сцепленных вопроса — включает ли участник режим поиска вариантов **сам, без подталкивания** (инициатива), и на какой круг решений этот режим распространяется (охват: главный вопрос → подрешения внутри пути → сама постановка задачи). Здесь считается только факт и охват порождения вариантов.

**Счётная единица — альтернатива.** Альтернатива — **второй способ добиться того же результата**, между которым и первым предполагается выбор. Не альтернативы:

- **список задач** — «и то, и это, и ещё вот это»: между пунктами выбора не предполагается, их надо выполнить все;
- **переформулировка** одного и того же варианта другими словами;
- **сценарий будущего** — «что может случиться с миром» (это МК-2). Альтернатива — «что делать компании».

**Узел генерации:**

- **верхний вопрос** — главное стратегическое решение;
- **подрешение** — решение внутри уже выбранного пути (как именно выходить на рынок, как строить партнёрства, как ценообразовывать);
- **рамка задачи** — сама постановка вопроса и допущения, на которых она стоит.

**Стены.**

- **От ГА-2.** Откуда идеи берутся и насколько они экзотичны — ГА-2. Здесь это не считается: можно быть на верхнем уровне здесь, оставаясь ограниченным по ГА-2.
- **От ПР.** Выбор одного варианта из развилки с обоснованием — ПР. Здесь засчитывается сам факт порождения вариантов.
- **От МК-2.** Альтернатива — разное действие компании; сценарий — разное будущее состояние мира.

**Немонотонность гейтов.** Это единственная способность, где верхний гейт достижим без нижнего: переопределить задачу можно, не ветвя подрешения. Если верхний гейт пройден, а нижний нет, уровень берётся **по верхнему**, и ставится флаг «перепрыгнутая граница» (§10.1, шаг 6).

**Лестница гейтов.**

| Гейт | Условие |
|------|---------|
| **G2** | Есть хотя бы один альтернативный вариант. |
| **G3** | Поиск инициирован самим участником (не по запросу вопроса) **И** дано ≥2 альтернативы для главного вопроса. |
| **G4** | Генерация распространяется на подрешения как повторяющийся процесс. |
| **G5** | Порождены альтернативные формулировки задачи **и/или** поставлены под сомнение допущения постановки. |

**L1 · Не проявлено**

Вход на уровень — по отсутствию: во всём ответе нет ни одной альтернативы. Путь идёт напрямую от проблемы к одному решению, и решение подано как единственно возможное. Число перечисленных действий значения не имеет: десять дел одной логики альтернативами не являются.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Ни одной конкурирующей опции. Предложен ровно один образ действий; нигде не звучит «либо… либо», «альтернатива», «другой путь»; следов рассмотрения отвергнутых вариантов нет.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Маршрут «проблема → решение» без промежуточного шага «а какие есть пути вообще».
  - Несколько действий, которые не конкурируют: список задач, а не альтернатив.
  - Исполнительский тон: «делаем то-то», без единого «или».
  - «Ответ очевиден: …».
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** достаточно одной настоящей альтернативы — второго способа добиться того же результата, а не второй задачи в списке.
- **Дисквалификаторы:**
  - **Длинный список дел.** «Нанять, обновить, выйти, оптимизировать, усилить» выглядит богато, но это перечень задач одной логики.
- **Примеры:**
  - ✅ «Компании нужно улучшить продукт и выйти в новый сегмент» → L1: одно слитное решение без развилки.
  - ❌ «Раз спрашиваете варианты — вот три пути роста…» → L2.

**L2 · Ближний контур — «варианты по запросу, только наверху»**

Вход на уровень — один обязательный признак: есть хотя бы одна альтернатива. Верхняя граница — по источнику хода и по охвату: пространство опций открылось потому, что вопрос прямо попросил варианты, и только для верхнего вопроса. Число выданных по запросу вариантов уровень не поднимает.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Альтернатива, выданная в ответ на прямой запрос. Засчитывается: несколько опций для верхнего вопроса там, где вопрос просил «какие есть варианты» или «предложите альтернативы». Не засчитывается: список задач; переформулировка одного варианта.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Альтернативы сидят кучно ровно в том абзаце, который отвечает на вопрос-про-варианты, и больше нигде.
  - Весь остальной ответ идёт одним ходом.
  - Обозначено, что между опциями предстоит выбор, но рамку «вот варианты» задал вопрос, а не участник.
  - Внутри выбранного пути снова действует по первому варианту.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужны оба признака вместе — поиск, инициированный самим участником там, где вопрос его не требовал, и ≥2 альтернативы для главного вопроса.
- **НЕ ТРЕБУЕТСЯ:** экзотичность идей (это ГА-2); обоснование выбора (это ПР).
- **Дисквалификаторы:**
  - **«Длинный список по запросу = высоко».** Даже пять вариантов, выданных строго в ответ на прямой запрос, остаются здесь. Уровень поднимает инициатива, а не длина списка.
- **Примеры:**
  - ✅ «Раз спрашиваете варианты — вот три…», а весь остальной ответ идёт одним ходом → L2.
  - ❌ Отвечая на вопрос, который просил рекомендацию, участник по своей инициативе говорит «здесь возможны как минимум три принципиально разных пути…» → L3.

**L3 · Средний контур — «инициатива на главном вопросе»**

Вход на уровень — конъюнкция двух признаков: поиск инициирован самим участником там, где вопрос его не требовал, **и** дано ≥2 реальные альтернативы для главного вопроса. Верхняя граница — по охвату: внутри выбранного пути генерация не повторяется, подрешения решаются по первому варианту. Пышность одной развилки уровень не поднимает.

- **ДЕЛАЕТ — обязательные признаки, оба.**
  1. Спонтанное открытие пространства. Засчитывается: участник сам останавливается и говорит по сути «здесь есть несколько путей» там, где вопрос вариантов не просил. Не засчитывается: варианты, выданные строго в ответ на прямой запрос.
  2. ≥2 реальные альтернативы для главного вопроса. Засчитывается: конкурирующие пути, между которыми предстоит выбирать. Не засчитывается: переформулировки одного и того же; список задач, которые надо выполнить все.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Формулировка «здесь возможны как минимум три принципиально разных пути…», а дальше выбор.
  - Разовое открытие пространства на входе, а не режим на каждом узле.
  - Постановка вопроса принимается как данность.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** генерация должна повторяться на подрешениях и выглядеть как систематический процесс, а не как единичное открытие пространства.
- **НЕ ТРЕБУЕТСЯ:** число альтернатив сверх двух; кросс-отраслевые источники (это ГА-2).
- **Дисквалификаторы:**
  - **«Одна богатая развилка = следующий уровень».** Одна, пусть очень подробная, развилка на главном вопросе — даже с четырьмя опциями и разбором каждой — остаётся здесь.
  - **«Много вариантов на одном узле».** Десять опций для главного вопроса при отсутствии генерации на подрешениях — по охвату по-прежнему этот уровень.
- **Примеры:**
  - ✅ Вопрос просил рекомендацию, а участник сам разложил три конкурирующих пути и затем выбрал → L3.
  - ❌ «На этом этапе A/B/C… выбрал A; внутри A снова развилка A1/A2…» → L4.

**L4 · Дальний контур — «генерация на каждом узле»**

Вход на уровень — один обязательный признак: генерация повторяется на подрешениях внутри выбранного пути, то есть ветвление проходит через ответ, а не сидит в одном месте. Верхняя граница — по контуру: постановка задачи принимается как данность, на саму рамку генерация не выносится.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Повторяющаяся генерация на подрешениях. Засчитывается: варианты разворачиваются не только на верхнем вопросе, но и внутри выбранного пути — «выбрал выход на рынок → каким способом: прямые продажи / партнёрская сеть / маркетплейс; выбрал партнёрскую сеть → эксклюзивные или открытые». Не засчитывается: множество опций на одном узле; ремарка «варианты возможны» без развёрнутых опций.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Каскад развилок разной глубины; ответ ветвится как дерево, а не как один куст.
  - Повторяющееся «здесь возможны варианты» на разных уровнях вложенности.
  - Пространство держится открытым на нескольких уровнях.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** генерация должна развернуться на рамку — не «какие пути внутри задачи», а «какая вообще это задача»; допущения постановки должны быть поставлены под сомнение.
- **НЕ ТРЕБУЕТСЯ:** источники идей вне отрасли (это ГА-2); обоснование выбора (это ПР).
- **Дисквалификаторы:**
  - **Широко, но не вглубь.** Десять опций для главного вопроса и ни одной для подрешений — это охват предыдущего уровня.
- **Примеры:**
  - ✅ «На этом этапе A/B/C… выбрал A; внутри A снова развилка A1/A2; дошли до денег — подписка или транзакции?» → L4.
  - ❌ «Мы исходим из того, что цель — нарастить долю рынка; но задача может звучать иначе…» → L5.

**L5 · За пределами контура — «генерация применяется к самой задаче»**

Вход на уровень — дизъюнкция: достаточно одного признака из двух. Уровень достижим без прохождения предыдущей границы — переопределить задачу можно, не ветвя подрешения; в этом случае ставится флаг «перепрыгнутая граница». Ограничений сверху нет.

- **ДЕЛАЕТ — обязательные признаки, хотя бы один из двух.**
  1. Альтернативные формулировки задачи. Засчитывается: порождена вторая постановка вопроса, и показано, что она ведёт к другим решениям, — «мы исходим из того, что цель — нарастить долю рынка; но задача может звучать иначе: как сделать так, чтобы доля рынка перестала быть ключевой метрикой». Не засчитывается: уточнение своей рекомендации, пересказ её другими словами, добавленная оговорка.
  2. Допущение постановки, поставленное под сомнение. Засчитывается: допущение явно вытащено и сделано предметом генерации — «мы предполагаем [X] — а что если [не-X]?». Не засчитывается: риторический вопрос «а может, вообще всё делать иначе?» без демонстрации, какие именно другие стратегии это открывает.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Обороты «а тот ли это вопрос», «переформулируем саму задачу», «каждая формулировка задачи открывает своё пространство решений».
  - Несколько альтернативных фреймов задачи, а не только альтернативные решения внутри одного фрейма.
- **НЕ ДЕЛАЕТ:** ограничений сверху нет.
- **Дисквалификаторы:**
  - **«Переформулировал ответ ≠ переформулировал задачу».** Уточнение рекомендации уровень не открывает.
  - **Риторический вопрос без пространства.** Нужно показать, что альтернативный фрейм действительно ведёт к другим решениям.
- **Примеры:**
  - ✅ «Мы исходим из того, что цель — нарастить долю рынка; но задача может звучать иначе — как сделать так, чтобы доля рынка перестала быть ключевой метрикой», и дальше показано, к каким другим решениям это ведёт → L5.
  - ❌ «А может, вообще всё делать иначе?» без единой открывшейся стратегии → уровень определяется по фактически порождённым вариантам.

### ГА-2 · Привлечение идей из разных областей

**Навык:** Генерация стратегических альтернатив (ГА)
**Тип прогрессии:** наращивание (А)

**Что измеряет:** откуда участник черпает идеи и как далеко тянется за ними — от рефлекторного зеркального хода через собственный опыт и отраслевой репертуар к заимствованию из чужих отраслей и переносу абстрактных паттернов. Здесь важно только происхождение и широта логики, а не количество вариантов и не выбор.

**Счётная единица — источник идеи.** Различаются пять источников, и они образуют шкалу:

- **зеркальный ход** — решение повторяет формулировку проблемы с обратным знаком; происхождения у него нет;
- **свой репертуар** — собственный опыт или очевидная практика своей отрасли;
- **разные механизмы своего репертуара** — качественно разные стратегические логики, все отраслевые;
- **чужая отрасль** — явно названный источник вне своей сферы, с адаптацией механизма;
- **абстрактный паттерн** — структурная закономерность, держащаяся в несопоставимых сферах, применённая как генератор новой идеи.

**Что считается чужой отраслью.** Источник, взятый из материалов кейса — практика другого подразделения, история другой компании из справки, — другой отраслью **не является**: границу он не открывает.

**Стены.**

- **От ГА-1.** Сколько альтернатив и насколько систематично они порождаются — ГА-1. Один-единственный кросс-отраслевой перенос может дать высокий уровень здесь при низком ГА-1.
- **От ПР.** Здесь порождается пространство опций; выбор внутри него — ПР.
- **От МК-2.** Альтернативы — разные действия компании; сценарии — разные будущие состояния мира.
- **Ортогональность.** ГА-1 и ГА-2 независимы, формального ограничения между ними нет (§9.6). Систематичный генератор из своей отрасли (высокий ГА-1, низкий ГА-2) и единичный кросс-отраслевой перенос без систематики (высокий ГА-2, низкий ГА-1) — обе комбинации реальны.

**Лестница гейтов.**

| Гейт | Условие |
|------|---------|
| **G2** | Решение опирается на какую-либо практику или логику, а не на зеркальный ход. |
| **G3** | Есть ≥2 альтернативы на принципиально разных механизмах. |
| **G4** | Есть явное заимствование из другой отрасли с названным источником и перенесённым механизмом. |
| **G5** | Сформулирован абстрактный паттерн, породивший решение вне исходных примеров. |

**L1 · Не проявлено**

Вход на уровень — по отсутствию источника: решение зеркалит проблему, повторяя её формулировку с обратным знаком, и не опирается ни на какую практику, логику или аналогию. Происхождения у хода нет: он не взят ниоткуда, он отражение проблемы. Оценивается именно источник, а не качество идеи: зеркальный ход может оказаться верным по существу и всё равно остаться здесь. Достаточно одной опоры на репертуар — «в таких случаях обычно делают…» — чтобы этот уровень не ставить.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Зеркальный ход без источника. Решение — прямая инверсия проблемы; ни собственного опыта, ни отраслевой практики, ни аналогии за ним не стоит.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - «Выручка падает — надо поднять продажи. Продукт устарел — обновить».
  - Ход не имеет происхождения: он просто отражение проблемы.
  - Логика за пределами самой проблемы не привлекается.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** достаточно, чтобы решение опиралось хоть на какую-то практику или логику. Как только появляется «в таких случаях обычно делают…» — это уже опора на репертуар.
- **Примеры:**
  - ✅ «Выручка падает — надо поднять продажи» → L1.
  - ❌ «В e-commerce отток решают лояльностью и персонализацией» → L2.

**L2 · Единичный элемент — «знакомый инструмент из своего опыта»**

Вход на уровень — один обязательный признак: решение вытянуто из знакомого репертуара — собственного опыта или очевидной практики своей отрасли. Верхняя граница — по разбросу механизмов: если вариантов несколько, все они — одна логика в разных настройках.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. Решение из знакомого репертуара. Засчитывается: «в таких ситуациях обычно делают X», «стандартно это решается через Y» — идея имеет происхождение, но узкое. Не засчитывается: зеркальный ход без источника.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Отраслевой дефолт: «в e-commerce отток решают лояльностью и персонализацией».
  - Несколько ходов одной механики в разных дозировках: «дешевле / быстрее / больше того же».
  - Аналогии за пределами своей отрасли не ищутся.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужны ≥2 альтернативы на принципиально разных механизмах, а не вариации одной.
- **НЕ ТРЕБУЕТСЯ:** систематичность генерации (это ГА-1); число вариантов.
- **Дисквалификаторы:**
  - **Три варианта одной логики** — главная ловушка. «Снизить цену / добавить фич и поднять цену / выйти в новый сегмент с тем же продуктом» выглядят как три альтернативы, но механизм один: продать тот же продукт большему числу людей. Разные параметры одной стратегии не равны разным механизмам.
- **Примеры:**
  - ✅ «В e-commerce отток решают лояльностью и персонализацией» → L2.
  - ❌ «Три принципиально разных стратегии: лидер по цене через масштаб / премиальная ниша / платформенная модель» → L3.

**L3 · Множественные элементы — «разные механизмы из своего репертуара»**

Вход на уровень — один обязательный признак: ≥2 альтернативы на принципиально разных механизмах. Верхняя граница — по источнику: все механизмы взяты из стандартного репертуара своей сферы, ни одна идея не привезена извне отрасли. Современный отраслевой словарь («платформа», «экосистема», «маркетплейс») чужой сферой не является.

- **ДЕЛАЕТ — обязательный признак, один.**
  1. ≥2 альтернативы на принципиально разных механизмах. Засчитывается: качественно иные стратегические логики — «лидер по цене через масштаб / премиальная ниша / платформенная модель». Не засчитывается: вариации одной механики в разных настройках.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Разброс механизмов сделан осознанно: участник явно отделяет «варианты одной логики» от настоящих альтернатив.
  - Все механизмы — из стандартного профессионального репертуара.
  - Ссылок на модели или опыт из других областей нет.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** нужно явное заимствование из другой отрасли с названным источником и перенесённым рабочим механизмом.
- **НЕ ТРЕБУЕТСЯ:** систематичность генерации (это ГА-1); число механизмов сверх двух.
- **Дисквалификаторы:**
  - **«Модный термин = чужая сфера»** — главная ловушка. «Платформа», «экосистема», «маркетплейс» — современный отраслевой репертуар, признак этого уровня, а не следующего. Следующий требует явного «вот как это устроено в [конкретная другая отрасль] — перенесём принцип сюда».
  - **Источник из кейса.** Практика другого подразделения или история другой компании из справки другой отраслью не является.
- **Примеры:**
  - ✅ «Три принципиально разных стратегии: лидер по цене через масштаб / премиальная ниша / платформенная модель» → L3.
  - ❌ «Это как в медиа: газеты оптимизировали печать вместо перехода в цифру — значит, и здесь надо переосмыслить сам формат взаимодействия с клиентом» → L4.

**L4 · Интегрированная картина — «перенос из другой отрасли, привязанный к примеру»**

Вход на уровень — конъюнкция двух признаков: явно названный источник вне своей отрасли **и** перенесённый рабочий механизм с адаптацией к своей ситуации. Отсылка без содержательного переноса уровень не открывает. Верхняя граница — по степени обобщения: перенос остаётся привязан к конкретному примеру-источнику, это аналогия, а не абстрагированный паттерн.

- **ДЕЛАЕТ — обязательные признаки, оба.**
  1. Явно названный источник из другой отрасли. Засчитывается: «ситуация как в [медиа / логистике / финтехе]: там сделали так-то». Не засчитывается: источник из материалов кейса; «модный термин» из своего репертуара.
  2. Перенесённый механизм с адаптацией. Засчитывается: сказано, что именно из чужой модели применимо и почему, и как это ложится на свой контекст. Не засчитывается: «сделаем как Uber, но для X» без содержательного переноса — это ярлык-отсылка, и по существу уровень остаётся ниже.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Под привнесённую логику переформулируется и сама задача.
  - Работа идёт с аналогией «X похоже на Y», а не с обобщённым паттерном.
- **НЕ ДЕЛАЕТ — то есть чтобы выйти на следующий уровень:** за примером должен быть вынут абстрактный механизм и назван как принцип, применимый к классу ситуаций, и из него должно родиться решение, которого не было ни в одном исходном контексте.
- **НЕ ТРЕБУЕТСЯ:** число заимствований; систематичность генерации (это ГА-1).
- **Дисквалификаторы:**
  - **Референс ради референса** — главная ловушка. Бренд-метафора без перенесённого механизма признак 2 не открывает.
- **Примеры:**
  - ✅ «Это как в медиа: газеты оптимизировали печать вместо перехода в цифровые платформы — значит, и здесь надо переосмыслить сам формат взаимодействия с клиентом» → L4: оба признака.
  - ❌ «Сделаем как Uber, но для X» → признак 2 не открыт.

**L5 · Системная картина — «абстрактный паттерн, порождающий новое»**

Вход на уровень — конъюнкция двух признаков: сформулированный абстрактный паттерн — структурная закономерность, держащаяся в несопоставимых сферах, — **и** порождённое из него решение или постановка, отсутствовавшие во всех исходных контекстах. Ограничений сверху нет.

- **ДЕЛАЕТ — обязательные признаки, оба.**
  1. Сформулированный абстрактный паттерн. Засчитывается: не «здесь как в отрасли Z», а «есть паттерн: во всех сферах, где [структурное условие], возникает [следствие]» — принцип назван содержательно. Не засчитывается: ярлык «здесь есть общий паттерн» без названного механизма.
  2. Порождение из паттерна. Засчитывается: из принципа выведено решение или постановка, которых не было ни в одном исходном контексте, — это порождение, а не адаптация. Не засчитывается: пересказ исходного примера в обобщённых словах.
- **ДЕЛАЕТ — типичные формы уровня. Ни одна не обязательна: служат для узнавания, не для проверки.**
  - Структурные связи между внешне несопоставимыми явлениями, названные как принцип.
  - Принцип работает как генератор, а не как иллюстрация.
- **НЕ ДЕЛАЕТ:** ограничений сверху нет.
- **Дисквалификаторы:**
  - **Богатая аналогия** — главная ловушка. Подробная, детально развёрнутая аналогия с одной отраслью остаётся предыдущим уровнем, как бы красиво она ни звучала.
  - **Паттерн на словах.** Заявление о наличии паттерна без формулировки механизма и без порождённого решения — ярлык.
- **Примеры:**
  - ✅ «Есть паттерн: в любой отрасли, где посредник контролирует доступ к потребителю, рано или поздно появляется технология, убирающая посредника — значит, вопрос не „как стать лучшим посредником", а „как создать ценность вне посреднической позиции"» → L5: оба признака.
  - ❌ «Здесь работает общий паттерн, как везде» → признак 1 не открыт.

## Приложение Б. Форма выдачи судьи

Судья выдаёт один объект на участника. Поля обязательны все.

```json
{
  "участник": "<идентификатор>",
  "версия_методологии": "methodology_for_imp_v1",
  "способности": [
    {
      "код": "МК-1",
      "уровень": 3,
      "последний_пройденный_гейт": "G3",
      "свидетельства": [
        { "гейт": "G2", "цитата": "<дословно из ответа>" },
        { "гейт": "G3", "цитата": "<дословно из ответа>" }
      ],
      "непройденный_гейт": { "гейт": "G4", "чего_не_хватило": "<признак>" },
      "флаги": []
    }
  ],
  "навыки": [
    { "код": "МК", "балл": 6, "ярлык": "L3", "асимметрия": 0 }
  ],
  "итог": { "балл": 30, "индекс": 50, "ярлык": "L3" },
  "флаги": []
}
```

**Допустимые значения флагов:**

| Флаг | Когда ставится |
|------|----------------|
| `спорный_гейт` | сомнение не разрешено; уровень взят ниже (§10.1, шаг 5). Указывается граница и цитата |
| `перепрыгнутая_граница` | верхний гейт пройден, нижний нет (только ГА-1) |
| `асимметричный_навык` | разница уровней внутри навыка ≥ 2 (§9.5) |
| `нарушение_зависимости` | АК-2 > АК-1 либо ПР-2 > ПР-1 + 1 (§9.6) |
| `устойчивость_ненаблюдаема` | ПР-2 оценена без стресс-теста; потолок L3 (§9.7) |
| `расхождение_основная_контрольная` | разница ≥ 2 уровня между ролями (§9.8) |
| `узкое_покрытие_при_факторе_извне` | АК-1 L4 поставлен при факторе за пределами кейса и узком покрытии |
| `стремится_к_верхнему` | ПР-1 L4 при слабо выраженных верхних маркерах |

**Правила заполнения:**

1. `свидетельства` содержат по одной дословной цитате на каждый пройденный гейт. Пересказ не допускается.
2. `непройденный_гейт` заполняется всегда, кроме уровня 5: судья называет, какого именно признака не хватило.
3. `уровень` — целое от 1 до 5. Дробных значений и диапазонов не бывает.
4. `балл` навыка = сумма уровней двух его способностей; `итог` = сумма пяти баллов; `индекс` = `(итог − 10) / 40 × 100`, округление до целого.
